# Work 创作约定

工程ID见`work.json`。先运行`bcr-work context ID --task TASK`，按必要清单读取[当前状态](docs/STATUS.md)与本期要求；历史、原始数组和共享引擎源码按需查询。当前状态只维护范围、已验收证据、未完成项和下一步。

- 根层配置是人工输入，`src/`保存表现与模型，`docs/`保存当前创作说明，历史修订放`docs/history/`。本期额外约束才补入本文件，通用环境与交付规则沿用父工作区约定。
- 文稿、数据、来源和画面分开，使用稳定语义ID；动画由帧号驱动。`cues.json`为动作声明，`.bcr/build/`为派生。类型或模型检查不代表正式镜头已经完成。
- TTS按完整语义段生成，实际录音与对齐决定正式时序；草稿可以预览，不能作为正式导出。私有参考与原始录音在`media/`，必须保留并从公开包排除；声音使用已有确认范围。
- 通用制作走`bcr-work`，本期只维护业务检查。输入稳定后检查受影响部分，不逐轮新增报告；新视频使用AV1、优先NVENC。短样片、全片、自动检查和实际视听分别记录，交付通过独立暂存及`release`保留旧版本身份。
