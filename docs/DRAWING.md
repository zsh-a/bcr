# 绘图工作区

入口为 `/diagram`，也可从工作区的「阅读与知识」分组打开「绘图」。默认隐藏全局栏，保留一层操作栏与原生 Excalidraw 画布；主题、文件抽屉、对话框、搜索和 AI 助手复用 Studio 的宿主机制。

## 使用

- 新建空白画布，或从流程图、系统架构模板开始。支持原生图形、文字、连线、自由绘制和内嵌图片。
- 标题失焦后保存，画布修改延迟 450 ms 自动保存。只有显示「已保存」才表示本次内容已提交到本机。
- 「我的图表」查找已保存的文件；工作区全局搜索也会索引标题。
- 「整理布局」整理选中节点，未选中时整理全部未锁定的顶层矩形、椭圆和菱形；文字与相连箭头随节点移动。
- 「从 Mermaid 插入」将流程描述转换为可编辑图形，追加到当前画布。仅能生成图片的 Mermaid 类型会明确拒绝，不伪装成可编辑图形。
- 「图表操作」导入 `.excalidraw`，或导出可编辑文件、SVG、PNG；导入创建独立文件。复制笔记引用得到带图表 ID 的本地 Markdown 链接。

从画布点击「AI 绘图」打开现有助手。先配置可用的模型接口，然后可以说「画出这个系统的架构图」「把当前图中的缓存放到 Worker 下方」「整理选中的节点」。只读调用直接执行，创建、修改和布局通过宿主的变更预览与审批后执行。

## 数据与生命周期

**Excalidraw 原生 scene 是唯一的画布数据源**：`elements + appState + files`。AI 读取的是派生的语义投影，不额外维护一份容易与手动编辑失配的图模型。保存的 appState 只包含画布背景和网格大小；选择、平移、缩放、当前工具与主题属于临时 UI 状态。

浏览器使用独立 IndexedDB `bcr-diagrams`，每个图表一条文档记录，轻量索引不含图片或画布内容。文档与索引在同一个严格持久化事务中提交；写入队列配合 Web Locks 序列化窗口之间的保存，每次写入从持久存储重新读取 revision。旧窗口无法覆盖较新的版本。冲突时保留内存草稿，可以导出后重新打开；当前不自动合并多窗口编辑。

`createWorkspaceServices` 拥有存储生命周期，插件只注册搜索投影、工具和结果渲染。工作区更新前会刷新草稿；关闭有未保存修改的页面时会提示。异常退出仍可能丢失尚未提交的最后一段修改。

存储损坏、未知版本或写入失败会明确报错，不用空白数据覆盖原文件。单文件限 30 MB、10,000 个原生元素。数据按站点来源保存；切换域名或端口是另一个存储空间，清理浏览器数据会移除图表。可编辑文件适合备份与转移，目前不包含 Git 同步或协作服务。Studio 仍持有计算项目的独占会话锁，图表存储的版本防护不意味着支持同时打开两个完整 Studio 会话。

## AI 接口

能力 `diagram.library` 属于共享领域，其他 App 内的助手也可以查找、创建和修改图表，不要求挂载绘图编辑器。

| 工具             | 输入与作用                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| `diagram_list`   | 可选 `query`、`offset`，按页返回 40 个文件摘要                                                          |
| `diagram_read`   | 可选 `id`，省略时使用当前图表；返回元素、选区、revision，每页 100 个元素。后续分页必须携带该 revision   |
| `diagram_create` | `requestId`、`title`，以及 `graph` 或 `mermaid` 中的一种；稳定请求 ID 支持同内容重试                    |
| `diagram_patch`  | `id`、当前 `revision`、`patch`，支持 `addNodes`、`addEdges`、`update`、`remove`，按稳定元素 ID 局部修改 |
| `diagram_layout` | `id`、当前 `revision`，可选元素 `ids` 与 `direction: RIGHT / DOWN`                                      |
| `diagram_export` | `id` 与 `format: excalidraw / svg`，返回有大小限制的文本；大文件使用工作区下载                          |

创建示例：

```json
{
  "requestId": "cache-flow-1",
  "title": "缓存读取流程",
  "graph": {
    "direction": "RIGHT",
    "nodes": [
      { "id": "request", "label": "接收请求" },
      { "id": "cache", "label": "读取缓存", "type": "diamond" },
      { "id": "response", "label": "返回结果" }
    ],
    "edges": [
      { "id": "request-cache", "source": "request", "target": "cache" },
      { "id": "cache-response", "source": "cache", "target": "response", "label": "命中" }
    ]
  }
}
```

修改必须先读取当前 revision。未指定的原生元素和附件保持不变；删除节点会清理附属标签及连接，锁定元素拒绝修改。编辑器打开时，一批 AI 修改进入原生历史，可一次撤销。审批等待期间发生手动修改，会使旧预览失效，助手需要重新读取画布后再操作。

SVG 工具结果可以在助手里显示预览，但模型收到的是 SVG 文本，当前没有多模态图片回传。首版没有外部 MCP 服务；这些工具定义和场景操作函数可供之后的桥接层复用。

## 加载与验证

Excalidraw、Mermaid 转换器和布局引擎按需加载；ELK 布局在独立 Worker 中运行。字体资源由构建插件从 SDK 生成并使用同源路径 `/diagram-assets/fonts/`，无需运行时字体 CDN。独立安装入口 `/pwa/diagram/` 沿用共享 PWA 外壳，预缓存绘图模块、布局 Worker 与默认字体；其他可选字体在线使用后再缓存。AI 模型请求需要可用的接口连接。

```sh
bun run check
bun run test
bun run dev
# 另一个终端；也可设置 BASE_URL 指向生产预览
bun run test:browser:diagram
```

单元测试覆盖原子提交、损坏数据保留、失败重试、创建去重、草稿竞态和版本冲突。浏览器走查使用实际领域工具与模拟模型 SSE，覆盖原生绘图、审批、局部修改、撤销重做、过期预览、Mermaid、导入导出、刷新恢复、多窗口保存和主题/小屏对话框。
