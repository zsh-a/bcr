# 绘图工作区

[文档](README.md) → 绘图

入口为 `/diagram`，独立安装入口为 `/pwa/diagram/`。画布使用 Excalidraw，工具栏、图表列表、菜单、弹窗与提示复用工作区控件。

## 使用

| 入口            | 操作                                         |
| --------------- | -------------------------------------------- |
| 空白画布／模板  | 自由绘制，或从流程图、系统架构开始           |
| 我的图表        | 搜索与打开本机图表                           |
| 整理布局        | 整理选中节点；未选中时处理可布局的未锁定节点 |
| 从 Mermaid 插入 | 将流程描述追加为可编辑图形                   |
| 图表操作        | 新建、导入、适应画布、下载、复制引用与删除   |
| AI 绘图         | 打开共享助手，生成或局部修改图表             |

标题失焦后保存，画布修改自动保存；「已保存」表示内容已提交到本机。导入 `.excalidraw` 会创建独立图表，导出支持可编辑文件、SVG 与 PNG。复制引用得到包含图表 ID 的 Markdown 链接，可放入知识库。

桌面常用操作保留在顶部，手机将整理布局与 Mermaid 插入收进更多菜单，为名称与保存状态留出空间。命令菜单支持方向键、Home/End、Escape 与焦点恢复；危险操作独立分组并确认。画布菜单保留清空、背景与帮助等原生操作。

控件跟随工作区主题，画布内容颜色保持文件语义。适应画布和插入后的定位尊重减少动态效果设置。

## 保存与恢复

原生 scene（`elements + appState + files`）是唯一画布数据源。保存的 appState 只包含背景与网格；选择、平移、缩放、当前工具和界面主题属于临时状态。

图表存入独立 IndexedDB `bcr-diagrams`。文档与轻量索引在同一事务中提交，Web Locks 串行化写入，revision 防止旧版本覆盖新内容。冲突时保留内存草稿，可先导出再重新打开；不自动合并多窗口编辑。

工作区更新前会刷新草稿，关闭未保存页面时提示；异常退出仍可能丢失尚未提交的修改。损坏数据与写入失败会报错，不用空白文件覆盖。文件限 30 MB、10,000 个原生元素，目前不提供 Git 同步或协作服务。

独立绘图 PWA 不创建 Studio 计算会话；宿主内使用时仍遵循工作区会话边界。来源、端口与清理站点数据的影响见[PWA 说明](INDEPENDENT-PWAS.md)。

## AI 接口

`diagram.library` 是共享领域能力，不要求打开画布。先配置模型连接，再使用「整理选中的节点」或「在 Worker 后增加缓存」等指令。只读工具直接执行，创建、修改和布局先展示预览并等待确认。

| 工具             | 作用                                                        |
| ---------------- | ----------------------------------------------------------- |
| `diagram_list`   | 按查询和分页返回图表摘要                                    |
| `diagram_read`   | 读取图表、选区与 revision；分页固定同一版本                 |
| `diagram_create` | 使用 graph 或 Mermaid 创建图表，稳定 requestId 支持重试     |
| `diagram_patch`  | 按稳定元素 ID 增删改，要求当前 revision                     |
| `diagram_layout` | 整理指定或全部可布局节点，要求当前 revision                 |
| `diagram_export` | 返回有大小限制的 excalidraw 或 SVG 文本；大文件使用界面下载 |

修改先读取 revision，未指定的元素和附件保持不变；锁定元素拒绝修改。审批期间画布变化会使旧预览失效。编辑器打开时，一批 AI 修改进入原生撤销历史，可整体撤销。

Mermaid 只接受能转换成可编辑图形的内容。SVG 可在助手中预览，工具向模型返回文本；当前不提供多模态图片回传或外部 MCP 服务。接口定义见 [agent.ts](../apps/studio/src/diagram/agent.ts)，场景操作见 [scene.ts](../apps/studio/src/diagram/scene.ts)。

## 加载与验证

编辑器、Mermaid 和布局引擎按需加载，ELK 在 Worker 中运行；默认字体从同源 `/diagram-assets/fonts/` 加载。PWA 缓存当前应用、布局 Worker 与默认字体，其他字体首次使用和 AI 请求需要网络。

```sh
bun run test apps/studio/tests/diagram-store.test.ts
BASE_URL=http://127.0.0.1:5199 bun run test:browser:diagram
```

浏览器检查需先启动 Studio，使用模拟模型而非真实密钥。覆盖原生绘制、AI 审批与局部修改、撤销重做、版本冲突、Mermaid、导入导出、刷新恢复，以及深浅主题、移动端菜单和键盘焦点。
