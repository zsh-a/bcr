# 本地 Agent 网关

网关 `http://127.0.0.1:3000/v1` 没有允许页面来源的 CORS 响应头时，浏览器不能直连。Studio 提供显式启用的开发 / 预览同源代理：

```sh
BCR_LOCAL_LLM=1 bun run dev --host 127.0.0.1
```

在 AI 助手「接口」中填写：

- 地址：`/api/llm/v1`
- 模型：`mimo-v2.6-pro`
- 密钥：网关要求时填写，仅保存在当前页面内存

代理固定转发到 `127.0.0.1:3000`，仅开放模型列表 GET 和对话 POST，拒绝非本地主机名及跨站来源；不接受客户端指定上游地址。支持流式响应。只在可信本地环境使用，不要通过隧道暴露开发服务器。

静态生产部署不包含该代理。生产环境应部署有鉴权的同源反向代理，或在网关显式允许页面来源；服务器上的 `127.0.0.1` 不代表访问者的电脑。

工具调用与回执使用结构化协议保留，拒绝审批也作为工具结果保存。请求失败会显示错误；尚未调用工具的失败可重试，已有工具记录时需先核实结果并发送新指令，避免重复写入。

## 真实模型回归

启动网关及开启代理的 Studio 后运行（会调用真实模型；仅在隔离浏览器中创建虚构测试笔记）：

```sh
BCR_AGENT_LIVE=1 BCR_APP_URL=http://127.0.0.1:5199 node scripts/verify-agent-live.mjs
```

覆盖流式对话、多轮上下文、跨领域检索、编辑批准 / 拒绝 / 再次调用、切换工作区使审批失效、禁用能力、取消与恢复、刷新持久化。报告写入系统临时目录，不包含接口密钥；模型输出具有非确定性。
