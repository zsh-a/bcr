# Reader 阅读界面

Reader 的渲染与导航按内容模型分离，不再让所有格式共用多栏布局。

- `ReadingView` 选择连续阅读或 `PagedReadingView`。PDF 固定采用连续页面。
- `PagedReadingView` 仅挂载当前章节；视口定义每页宽度，CSS 分栏负责排版，吸附标记定义翻页边界。分页和换章是不同操作，跨章时前进到首屏、后退到末屏。
- `SectionView` 是不订阅阅读进度的 memo 边界，高亮结果按内容和查询缓存。连续阅读仍保留全文 DOM，以支持全文选择、内部链接和文字锚点；它不是完整的章节虚拟列表。
- `ReaderEffects` 隔离进度持久化订阅，不再通过 App 将滚动更新传播到整个阅读界面。宿主搜索投影只随出版物变化重建。
- PDF 页面保留按原始宽高比计算的占位尺寸；视口附近才分配 Canvas，离屏清零位图，单文档最多同时执行两个渲染任务。页面壳和观察器仍按页保留。
- 启动时先恢复轻量出版物投影，只重新解析当前打开的二进制书籍。切换书籍后串行恢复新的当前书，不预先打开整个书库。批量恢复接口保留调用者优先级并支持逐本发布。
- `ReaderSheet` 统一设置、目录、书库、笔记和安装说明，使用原生 dialog top layer，并约束 Tab 循环和恢复触发点焦点。没有伪装成可拖拽控件的装饰把手。
- 移动端工具层覆盖在稳定阅读视口上，显隐只改变透明度和位移。阅读正文保持对称边距，书库操作不常驻阅读工具层。

## 备份与恢复

书库中的「备份与恢复」导出版本化 ZIP：`reader.json` 保存出版物投影、进度、书签、笔记与设置；`sources/<BLAKE3>` 保存原始本地文件。临时 Blob URL 不作为恢复依赖，二进制读物在目标设备重新解析。没有源文件的二进制读物会阻止导出，不会静默生成缺书的备份。远程图片等外部网页依赖不属于本地原文件备份范围。

- `readerBackup.ts` 负责格式验证、大小限制、CRC/内容摘要验证、去重和恢复准备，不依赖 React/store。
- `ReaderBackupPanel` 管理生成、下载、校验、预览、确认、取消与错误反馈。生成完成不代表文件已被用户下载保存。
- 恢复只新增 ID 和源内容摘要均未存在的读物；已有书籍、进度和笔记保留。设置需要单独勾选才替换。不提供覆盖整个书库的破坏性恢复。
- 全部待恢复读物准备完成后才合并到当前书库。取消或解析失败不发布部分书库；准备阶段已写入的内容寻址文件可能留在本地，不贸然删除可能共享的源文件。
- 合并后的保存失败会明确显示「尚未保存」并允许重试；已经载入内存的新增书籍不会伪装成持久化成功。
- 上限为 512 MiB 源文件与 64 MiB 清单，按文件顺序处理并流式计算摘要；ZIP 成品与恢复预览的 Blob 仍占用内存。这不是无限容量或流式磁盘备份，也不提供加密/云同步。

## 搜索与跳转

核心搜索为每次非重叠出现生成独立结果，保留 NFKC/大小写/空白归一化与原始 UTF-16 偏移映射。结果按书库与章节顺序展示，最多 80 条，达到上限时界面明确提示；可选择当前读物或整个书库。连续/分页视图根据文字 Locator 定位，不再强制滚到第一处高亮。

显式打开目录、搜索、书签、笔记或指定 PDF 页码时，先同步捕获离开前的位置。`ReaderStore` 维护有界 back/forward 栈；正常滚动和分页换章不进入栈。历史和搜索范围保存在本机会话中，恢复时校验读物与章节仍存在。返回后再次跳转会截断前进分支。`ReaderHistoryBar` 提供返回、前进、历史列表和上一/下一命中，作为浮动工具层，不改变阅读视口尺寸。

## PDF 文字与缩放

PDF.js `TextLayer` 与 Canvas 使用同一 CSS viewport；文字层支持系统选字/复制，搜索高亮保留 PDF 自身位置与旋转。扫描页没有可提取文字时会明确提示，不把 OCR 能力隐含在文字层中。

页码输入、前后页、适宽/整页计算和 40%–300% 缩放集中在 PDF 工具条；缩放保留当前页面内的垂直相对位置。整页适配按当前视口计算，之后可再次选择重新适配。渲染任务仍最多两个，每张画布约限制在 400 万 backing pixels；离屏同时释放文字 DOM 与画布。缩放和重渲染不应自动返回旧命中。尚未实现 OCR、PDF 表单/链接注释层、缩略图网格或自定义双指内容缩放；浏览器缩放未被禁用。

## 验证

`scripts/verify-reader-mobile.mjs` 使用隔离 Chromium 上下文，覆盖长文分页、单章节 DOM、翻页、刷新恢复、工具显隐几何稳定、横屏、模态焦点与 40 页 PDF 的位图回收及重渲染。其位图分配断言并非浏览器总内存测量。

`scripts/verify-reader-studio.mjs` 覆盖既有导入、搜索、文字锚点、主题、书签、笔记及刷新恢复。

`scripts/verify-reader-tools.mjs` 覆盖重复命中跳转与返回/前进、PDF 选字/页码/缩放/高亮、实际 ZIP 下载、重复备份预览、全新浏览器上下文的合并恢复与刷新。三者均纳入浏览器 CI。单元测试补充归一化偏移、损坏/缺失源文件、取消、重复内容与导航分支。

真实 iOS 键盘、安全区及低端设备帧率仍需真机验证；长单章节的排版成本仍与章节大小相关。
