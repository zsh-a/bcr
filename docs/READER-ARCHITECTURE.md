# Reader

[文档](README.md) → Reader

Reader 提供本地书库、全文搜索、书签、笔记与进度恢复。工作区入口为 `/reader`，独立安装入口为 `/pwa/reader/`。

## 阅读与导航

支持 TXT、Markdown、HTML、DOCX、FB2、EPUB、PDF 和 CBZ；格式识别与能力边界由 [Format Catalog](../packages/reader-core/src/formats.ts) 统一声明。

| 内容              | 阅读方式                                                 |
| ----------------- | -------------------------------------------------------- |
| TXT               | 连续阅读或按实际文字行测量的分页；章节识别与正文读取分离 |
| EPUB 等结构化文本 | 连续阅读或章节内多栏分页，保留标题、表格和插图           |
| PDF               | 连续页面、文字层、页码导航、缩放与缩略图                 |
| CBZ               | 图片阅读、阅读方向、整页适配、双击缩放与触屏翻页         |

书库支持筛选、收藏、重命名、最近阅读和批量管理。目录、搜索、书签与笔记跳转前保存当前位置；返回与前进恢复阅读位置，而不是重新打开书首。

手机底部工具提供常用导航与进度操作，设置和管理功能进入弹层。专注阅读隐藏工具，保留必要的章节与进度信息；工具显隐不改变正文几何。键盘、点按和翻页手势避让选字、长按与交互控件，减少动态效果设置会停用翻页动画。

界面控件跟随工作区主题，阅读纸张与内容配色独立。章节、排版和窗口变化后按文字或页面锚点恢复位置，不依赖固定页码。

## PDF

| 操作     | 当前行为                                                   |
| -------- | ---------------------------------------------------------- |
| 定位     | 支持页序、PDF 页面标签、目录与缩略图；输入错误在控件旁显示 |
| 缩放     | 适宽、整页与 10%–400% 自定义缩放，窗口变化时重新计算适配   |
| 触屏     | 双指缩放与双击放大，保留手势附近的页面位置                 |
| 文字     | PDF.js 文字层支持选字、复制与搜索高亮                      |
| 链接     | 支持文档内目标跳转与经过协议校验的外部链接                 |
| 页面浏览 | 缩略图分组按需加载，打开时显示当前页，可随时定位当前页     |
| 记录     | 书签和笔记保留页内位置，恢复时回到对应页面区域             |
| 配色     | 原色、纸张与夜间配色；缩略图跟随内容配色                   |

Canvas、文字层与链接层使用一致的页面几何。视口附近才渲染页面，离屏释放位图和文字 DOM；渲染队列限制并发与单页像素预算。页面占位仍保留原始宽高比，避免加载时跳动。

扫描页没有可提取文字时明确提示；Reader 当前不提供 PDF OCR 或可填写表单。源文件缺失或读取失败时提供重新导入入口。

实现入口：[PDF 阅读视图](../packages/reader-studio/src/reading/PdfReaderView.tsx)、[手势与适配](../packages/reader-studio/src/reading/usePdfViewport.ts)、[链接层](../packages/reader-studio/src/reading/PdfPageLinks.tsx)、[页面浏览](../packages/reader-studio/src/navigation/PdfPageBrowser.tsx)。

## 搜索与摘录

搜索支持当前读物与整个书库。结果按具体出现位置生成，保留原文 UTF-16 偏移；大小写、全角字符和空白归一化不会改变定位身份。首批最多展示 80 条，末尾可继续加载；书库搜索在读物间分配结果，避免单本书占满首批。

点击结果定位对应命中，并可使用上一处、下一处和返回导航。搜索失败保留结果并允许重试；失效命中显示错误，不猜测跳转位置。

同一章节内的短选段可加入资料集合并附笔记。采集先加载并固定原文，再校验文字位置；跨章节、超长或无法唯一对齐的选区会提示。独立 Reader 会先保存状态，再进入 Studio 处理资料集合，因此需要工作区资源可用。引用身份与迁移见[资料引用](RESEARCH-CITATIONS.md)和[Reader 资料包](RESEARCH-PACKAGE.md)。

## 书库备份与恢复

书库的「备份与恢复」导出版本化 ZIP，包含出版物、进度、书签、笔记、设置与本地原始文件。外部网页资源不随包保存，临时 Blob URL 不作为恢复依赖。

- 导出前检查源文件；缺少二进制源文件时阻止生成不完整备份。
- 导入先校验并展示预览，确认后合并。相同来源的记录映射到本机书籍，已有名称、收藏与进度优先保留。
- 书签和笔记去重；同一记录的编辑冲突保留两个版本。无法对齐的锚点单独报告，不回退到书首。
- 设置与历史需要单独选择才替换；重复导入不重复创建已恢复记录。
- 准备失败或取消不发布部分书库；已写入的共享源文件可能保留。最终保存失败会显示未保存状态并允许重试。

当前备份有源文件与清单大小限制，ZIP 成品及预览仍占用内存；它不是云同步、加密归档或无限容量备份。格式与恢复规则分别见 [readerBackup](../packages/reader-studio/src/persistence/readerBackup.ts) 和 [readerRestoreRecords](../packages/reader-studio/src/persistence/readerRestoreRecords.ts)。

Reader 使用书库写锁避免多个页面同时覆盖记录。第二个页面需等待原页面关闭后重试；此机制不提供多窗口协作。

## 实现结构

| 目录                        | 职责                                   |
| --------------------------- | -------------------------------------- |
| `adapters/`、`content/`     | 格式解析、正文按需读取、资源缓存与释放 |
| `reading/`、`pagination/`   | 连续文本、PDF、漫画及 TXT 分页         |
| `navigation/`、`search/`    | 目录、历史、进度、批注与命中定位       |
| `library/`、`persistence/`  | 书库管理、备份、编码与恢复             |
| `state/`、`runtime/`        | 唯一状态发布入口与运行时生命周期       |
| `typography/`、`workbench/` | 排版偏好与界面组合                     |

大文件正文通过 provider 按需读取，读取文字锚点前必须等待内容就绪。EPUB 按章节、CBZ 按图片、PDF 按页面文字读取；结构化文本可使用可重建的正文块缓存。搜索读取不填满显示缓存，备份以原始源文件为依据。

TXT 分页由浏览器测量真实行断点，再按 UTF-16 游标连续取页；只保留当前页、动画目标与有界预读。字号或视口改变时从锚点重排，页脚展示全书百分比，不预排整本书计算固定页数。长章节与超长段落仍有排版成本，缓存预算不等于浏览器总内存上限。

设计依据：[章节识别](TXT-CHAPTER-RESEARCH.md)、[分页高度](TXT-PAGINATION-RESEARCH.md)。运行时所有权与源码组织见 [Runtime 架构](RUNTIME-ARCHITECTURE.md#领域服务与代码职责)。

## 验证与边界

先按[开发指南](DEVELOPMENT.md#验证)启动服务器，再运行对应检查：

| 检查                                                                    | 覆盖                                         |
| ----------------------------------------------------------------------- | -------------------------------------------- |
| `verify-reader-studio.mjs`                                              | 多格式导入、搜索、批注与刷新                 |
| `verify-reader-pdf-experience.mjs`                                      | PDF 适配、定位、链接、缩略图、手势与搜索续载 |
| `verify-reader-txt-flow.mjs`                                            | 逐字分页、跨缓存回翻、位置恢复与动画         |
| `verify-reader-content.mjs`                                             | 延迟加载、资源释放与源文件重建               |
| `verify-reader-tools.mjs`、`verify-reader-restore-records.mjs`          | 搜索历史、备份与同源记录合并                 |
| `verify-mobile-knowledge-reader.mjs`、`verify-reader-navigation-ui.mjs` | 窄屏工具、弹层焦点、进度与导航               |
| `bun run test:pwa`                                                      | 生产版离线冷启动、写入保护与更新             |

脚本位于 `scripts/`，套件归属以[浏览器检查清单](../scripts/lib/browser-suites.mjs)为准。MOBI、AZW3 和 CBR 尚不支持；iOS 键盘、安全区及低端设备性能仍需真机验证。
