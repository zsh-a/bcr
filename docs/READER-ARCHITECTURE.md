# Reader 阅读界面

Reader 的渲染与导航按内容模型分离，不再让所有格式共用多栏布局。

- `ReadingView` 选择连续阅读或 `PagedReadingView`。PDF 固定采用连续页面。
- `PagedReadingView` 为 EPUB 等结构化格式保留章节内 CSS 多栏分页。TXT 使用 `TxtPageLayout` 按浏览器实测行断点分配正文页；读取段落与分页解耦，前后翻页均以原文 UTF-16 位置衔接，仅真实章节边界可产生自然尾页。
- `SectionView` 是不订阅阅读进度的 memo 边界，高亮结果按内容和查询缓存。连续阅读通过可见性挂载正文，超过 200 个章节时使用 `VirtualPublicationSections` 控制章节 DOM 数量；目录独立虚拟化。跨未挂载章节的全文选择不属于虚拟列表能力。
- `ReaderEffects` 隔离进度持久化订阅，不再通过 App 将滚动更新传播到整个阅读界面。宿主搜索投影只随出版物变化重建。
- PDF 页面保留按原始宽高比计算的占位尺寸；视口附近才分配 Canvas，离屏清零位图，单文档最多同时执行两个渲染任务。页面壳和观察器仍按页保留。
- 启动时先恢复轻量出版物投影，只重新解析当前打开的二进制书籍。切换书籍后串行恢复新的当前书，不预先打开整个书库。批量恢复接口保留调用者优先级并支持逐本发布。
- `ReaderSheet` 统一设置、目录、书库、笔记和安装说明，使用原生 dialog top layer，并约束 Tab 循环和恢复触发点焦点。没有伪装成可拖拽控件的装饰把手。
- 移动端工具层覆盖在稳定阅读视口上，显隐只改变透明度和位移。阅读正文保持对称边距，书库操作不常驻阅读工具层。

## 备份与恢复

书库中的「备份与恢复」导出版本化 ZIP：`reader.json` 保存出版物投影、进度、书签、笔记与设置；`sources/<BLAKE3>` 保存原始本地文件。临时 Blob URL 不作为恢复依赖，二进制读物在目标设备重新解析。没有源文件的二进制读物会阻止导出，不会静默生成缺书的备份。远程图片等外部网页依赖不属于本地原文件备份范围。

- `readerBackup.ts` 负责格式验证、大小限制、CRC/内容摘要验证、去重和恢复准备，不依赖 React/store。
- `ReaderBackupPanel` 管理生成、下载、校验、预览、确认、取消与错误反馈。生成完成不代表文件已被用户下载保存。
- 恢复只新增 ID 和源内容摘要均未存在的读物；已有书籍、进度和笔记保留。设置需要单独勾选才替换。不提供覆盖整个书库的破坏性恢复。
- 全部待恢复读物准备完成后才合并到当前书库。取消或解析失败不发布部分书库；准备阶段已写入的内容寻址文件可能留在本地，不贸然删除可能共享的源文件。
- 合并后的保存失败会明确显示「尚未保存」并允许重试；已经载入内存的新增书籍不会伪装成持久化成功。
- 上限为 512 MiB 源文件与 64 MiB 清单，按文件顺序处理并流式计算摘要；ZIP 成品与恢复预览的 Blob 仍占用内存。这不是无限容量或流式磁盘备份，也不提供加密/云同步。

## 搜索与跳转

核心搜索为每次非重叠出现生成独立结果，保留 NFKC/大小写/空白归一化与原始 UTF-16 偏移映射。结果按书库与章节顺序展示，最多 80 条，达到上限时界面明确提示；可选择当前读物或整个书库。连续/分页视图根据文字 Locator 定位，不再强制滚到第一处高亮。

显式打开目录、搜索、书签、笔记或指定 PDF 页码时，先同步捕获离开前的位置。`ReaderStore` 维护有界 back/forward 栈；正常滚动和分页换章不进入栈。历史和搜索范围保存在本机会话中，恢复时校验读物与章节仍存在。返回后再次跳转会截断前进分支。`ReaderHistoryBar` 提供返回、前进、历史列表和上一/下一命中，作为浮动工具层，不改变阅读视口尺寸。

## PDF 文字与缩放

PDF.js `TextLayer` 与 Canvas 使用同一 CSS viewport；文字层支持系统选字/复制，搜索高亮保留 PDF 自身位置与旋转。扫描页没有可提取文字时会明确提示，不把 OCR 能力隐含在文字层中。

页码输入、前后页、适宽/整页计算和 40%–300% 缩放集中在 PDF 工具条；缩放保留当前页面内的垂直相对位置。整页适配按当前视口计算，之后可再次选择重新适配。渲染任务仍最多两个，每张画布约限制在 400 万 backing pixels；离屏同时释放文字 DOM 与画布。缩放和重渲染不应自动返回旧命中。尚未实现 OCR、PDF 表单/链接注释层、缩略图网格或自定义双指内容缩放；浏览器缩放未被禁用。

## 验证

`scripts/verify-reader-mobile.mjs` 使用隔离 Chromium 上下文，覆盖长文分页、单章节 DOM、翻页、刷新恢复、工具显隐几何稳定、横屏、模态焦点与 40 页 PDF 的位图回收及重渲染。其位图分配断言并非浏览器总内存测量。

`scripts/verify-reader-studio.mjs` 覆盖既有导入、搜索、文字锚点、主题、书签、笔记及刷新恢复。

`scripts/verify-reader-tools.mjs` 覆盖重复命中跳转与返回/前进、PDF 选字/页码/缩放/高亮、实际 ZIP 下载、重复备份预览、全新浏览器上下文的合并恢复与刷新。三者均纳入浏览器 CI。单元测试补充归一化偏移、损坏/缺失源文件、取消、重复内容与导航分支。

真实 iOS 键盘、安全区及低端设备帧率仍需真机验证；长单章节的排版成本仍与章节大小相关。

## 统一内容加载

`ReaderSection` 保存稳定章节 ID、顺序、定位权重和源索引；延迟章节的 `text/html/imageUrl` 是缓存视图。读取文字锚点前必须等待内容，不能把未加载的空字符串当成原文。`contentInfo` 保存通用描述，旧 TXT 的 `textRange` 保持兼容。

`readerContent.ts` 管理每本书的 provider、并发去重、订阅固定、取消、LRU 和资源释放。`useSectionContent` 统一连续阅读、分页、漫画和 PDF 的可见内容订阅。最后一个订阅离开章节时取消未完成读取；离开整本书时清空正文缓存。预算允许可见章节临时超限，避免反复驱逐正在显示的内容，并非浏览器总内存的硬上限。

| 来源                                                         | 按需读取单元                 | 保留方式                                               |
| ------------------------------------------------------------ | ---------------------------- | ------------------------------------------------------ |
| TXT（至少 256 KiB）                                          | 原文件 UTF-8 段落范围        | 4 MiB / 128 项正文缓存                                 |
| EPUB（展开至少 256 KiB 或超过 32 章）                        | spine 章节及其图片           | 48 MiB / 16 项，驱逐时撤销 Blob URL                    |
| CBZ（至少 256 KiB 或超过 8 页）                              | 单张图片                     | 48 MiB / 12 项，驱逐时撤销 Blob URL                    |
| PDF（至少 256 KiB 或超过 32 页）                             | 页面文字                     | 与渲染器共享 PDF.js 文档，位图仍由可见性与渲染队列管理 |
| HTML / Markdown / DOCX / FB2（正文与标记合计至少 256K 字符） | 原有逻辑章节的规范化 JSON 块 | 可重建的二进制块存储，读取时采用相同正文缓存           |

小文件保留内联模型。结构化格式首次仍需完整解析，之后将正文迁入块存储；HTML/Markdown 的单个巨大逻辑章节仍是一个读取单元。EPUB 首次逐章建立文本长度和图片数量索引，但不保留全书正文及图片；PDF 首次仍读取页尺寸。此阶段不拆分逻辑章节，避免改变书签、引用及 UTF-16 偏移语义。

搜索通过 provider 逐块读取文字，不把正文或图片填入显示缓存；TXT 保留 worker 扫描。快照只保存索引，冷启动未打开的二进制读物通过 `attachDeferredSource` 首次读取时才打开源文件。备份携带原始源，结构化块缓存缺失时重新构建。显式交付 Document Studio 才物化完整内容。

`scripts/verify-reader-content.mjs` 覆盖多格式的冷加载、未打开书籍搜索、资源释放与重读、快照稳定性、备份源重建和实际视图显示；`verify-reader-large-txt.mjs` 覆盖大 TXT 的虚拟列表、远距离定位、搜索及刷新恢复。统一缓存与结构化块读取另有单元测试。

TXT 的标题识别、短段落连续分页和实现边界见 [调研与设计说明](TXT-CHAPTER-RESEARCH.md)。

分页正文的左、右四分之一区域支持桌面/手机点击上一页和下一页，中央区域切换工具栏。支持原生平滑滑动、淡出淡入、立体纸张翻转与无动画；减少动态效果时直接到达目标。拖选、长按、交互控件和修饰键点击不触发区域翻页。TXT 将连续操作放入有界队列，在已准备好的页面之间过渡；保存或输入接管时结束当前动画并取消剩余操作。

## TXT 连续页面窗口

- `txtPageMeasurement.ts` 使用一个不可见正文探针读取真实字体的行矩形，以二分搜索找到 UTF-16 行首。段落测量缓存最多 32 项或约 24000 字符；单个超长段落是允许超限的源读取单元。
- `txtPageLayout.ts` 是不依赖 DOM 的双向页面规划器，消费测量结果，在章节边界、段间距和版心高度约束下生成连续起止游标。回翻可从任意已保存的行首向前取内容，无需从书首重算。
- `useTxtPageFlow.ts` 管理异步加载、预读、动画、导航失效与进度保存。视图仅挂载当前屏，动画期间增加目标屏；预读相邻两屏，最多保留 8 个屏幕描述。字号、版心尺寸和字体加载变化会从文字锚点重建页面。
- `TxtPageContent.tsx` 渲染原文片段，携带原段落偏移；跨页续段不再次缩进。搜索、书签和批注使用原始章节 ID 与偏移，避免重复文本匹配到段首。
- 页脚展示全书百分比，不展示加载批次页码，也不预先加载全书以计算精确总页数。

TXT 分页的行高、段落策略与调研依据见 [分页高度调研](TXT-PAGINATION-RESEARCH.md)。默认首行缩进配合整行高度，也可选择段间留白；“宽松阅读”预设提供 22px 字号和 1.9 行高。

## 沉浸阅读

点击正文中央或桌面的“专注阅读”按钮隐藏操作栏，保留章节名、全书进度和本地时钟；点击章节名或按 Esc 恢复。工具栏和安静状态信息共用预留区域，只改变可见性，不改变正文几何。隐藏操作栏后焦点转入正文，键盘翻页继续可用。分页夜间主题使用中性深灰与柔和浅灰正文；成功导入提示在沉浸状态隐藏，失败与取消提示保留。

`verify-reader-txt-flow.mjs` 校验整本逐字遍历、跨缓存回翻、冷恢复、选择偏移、混排换行、四种动画及双页连续性；`verify-reader-focus.mjs` 校验桌面/手机工具显隐时几何与位置不变、键盘操作及工具恢复。原有高度、目录、搜索、大文件、其他格式和移动端测试继续运行。
