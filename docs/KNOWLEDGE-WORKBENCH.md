# 知识工作台：第一阶段

本阶段在现有 Markdown、草稿恢复、GitHub 同步和 Agent 审批写入之上，补齐日常写作与知识关联体验。不改变 `knowledge.v1` 状态格式，也不自动迁移用户数据；不是完整的 Obsidian Vault 或社区插件兼容层。

## 使用

- **快速打开**：侧栏入口或知识库活动时的 Ctrl/⌘+O。支持标题、标签、正文检索，↑↓ 选择，Enter 打开，Escape 取消；中文输入法确认不触发打开/创建。无结果时可明确创建笔记，同名笔记列出不同 ID，不静默选择目标。
- **标签页与导航**：保留最多 20 个标签页、50 条最近访问记录，支持前进/后退和收藏。标签页、最近访问、收藏只保存在当前浏览器，不进入 Git 同步或内容备份。最后一个标签页保持打开。
- **编辑状态**：当前工作区内最多缓存 20 篇笔记的撤销记录、选区和编辑器滚动位置；切换阅读模式不销毁编辑器。刷新后恢复正文依赖既有草稿机制，撤销记录不跨刷新保存。缓存正文与远端最新正文不一致时丢弃旧编辑会话，避免套用错误历史。
- **三种视图**：源码编辑、基础实时预览、独立阅读。基础实时预览隐藏非编辑位置的标题/强调/行内代码等标记，并将简单双链渲染为可点击名称；源码可随时查看。表格和任务列表在阅读模式按 GFM 渲染。图片仍使用安全占位，不自动请求远端图片。
- **写作辅助**：Ctrl/⌘+F 文内查找，列表续写，`/` 插入标题、任务、引用、日期、代码或表格。将普通笔记加上 `模板` 或 `template` 标签，即可在其他笔记插入其正文；支持 `{{title}}`、`{{date}}` 替换，不执行模板代码。
- **今日日记**：按设备本地日期打开或创建同一篇日记。重复点击不会覆盖正文，创建仍经过草稿保存屏障。
- **大纲与链接**：按需展开上下文区；桌面宽屏侧置，窄屏放在正文下方。支持标题定位、反向链接、出站链接及缺失目标提示。

## 链接语义

支持简单 `[[笔记标题]]`、`[[目标|显示名称]]`、`[[目标#标题]]`、`[[#当前标题]]` 和普通相对 Markdown 链接。`[[` 自动补全生成 `[[稳定ID|显示名称]]`，因此目标重命名不会改变引用身份。显示名称保持创建时的文字。

手写标题链接按 Unicode 归一化后的标题解析；同名或不存在的目标打开选择/创建界面，不自动写入。通过编辑器重命名时，原本唯一指向该笔记的标题双链会转换为稳定 ID 引用，保留原显示文字、别名和标题锚点。笔记重命名、引用更新及历史记录在同一次持久化写入中完成；受影响的其他笔记有未保存草稿或同步冲突时，整个保存会被拒绝，当前草稿保留。同名歧义链接不改写。

这项自动维护仅覆盖编辑器保存中的简单双链；普通 Markdown 链接、远端同步带来的重命名不自动重写。Agent 的单篇编辑审批保持单篇范围，不隐式修改其他笔记。基础双链要求位于同一普通文本片段内，不支持跨强调/代码节点的复杂别名。代码块、行内代码、转义链接和 HTML 节点不进入关系索引。

目前不解析 `![[嵌入]]`、块引用、引用式 Markdown 链接的反链、文件夹相对路径或 YAML 别名。不会将这些语法误报为已完成的兼容能力。

## 职责

- `markdownAnalysis.ts`：统一 Markdown 分析、阅读模式链接变换、目标解析与按正文缓存的关系索引。索引可重建，不是第二份正文。
- `renameLinks.ts`：基于重命名前的唯一解析结果规划双链替换，保留其余原始 Markdown；`store.ts` 在保存队列内校验并原子提交。
- `editorSessions.ts`：有界的临时编辑状态缓存；`draft.ts` 继续负责持久化草稿和保存屏障。
- `noteEditing.ts` / `livePreview.ts`：CodeMirror 补全、链接交互及显示扩展，不执行笔记存储操作。
- `workbench.ts` / `useWorkbench.ts`：校验、持久化浏览器个人布局与导航偏好。
- `NoteTabs`、`NoteSwitcher`、`NoteContext`：导航、搜索选择、上下文展示。
- `actions.ts` / `store.ts`：应用操作和唯一的持久化写入入口；原有同步、冲突和 Agent 校验保持不变。

## 后续阶段

1. 稳定 ID + 可读路径、扩展普通 Markdown 链接的重命名维护、块引用与嵌入；分记录存储和全文索引增量更新。
2. 文件夹、属性、独立回收站、图片与附件，及附件备份/同步策略。
3. Obsidian Vault 导入导出，保留目录、未知 YAML 属性和附件；与 BCR 完整恢复备份分开。
4. 分屏与保存布局、局部/全局图谱、属性表格/卡片、Canvas 和知识库扩展 API。
