# 个人知识库

[文档](README.md) → 知识库

知识库提供 Markdown 写作、文件夹、双向链接、附件与版本历史。工作区入口为 `/knowledge`，独立安装入口为 `/notes/knowledge/`；多设备使用见 [GitHub 同步](KNOWLEDGE-SYNC.md)。

## 写作与导航

| 入口             | 用途                                           |
| ---------------- | ---------------------------------------------- |
| 左侧笔记库       | 选择集合、搜索，切换全部／收藏／最近           |
| 编辑／源码／阅读 | 实时预览、原始 Markdown 与 GFM 阅读视图        |
| 信息面板         | 大纲、反向链接、出站链接、属性与附件           |
| 更多操作         | 日记、导入导出、版本历史、同步与备份           |
| 命令面板         | 按标题、标签和正文查找笔记，或执行当前可用操作 |

单击列表访问笔记，双击、Enter、命令面板或正文链接显式打开标签。标签可固定和关闭，最近访问与收藏保存在本机。关闭最后一个标签回到空状态。

桌面支持可调宽的资源侧栏与信息面板。手机通过模态弹层打开列表，初始焦点不会自动召唤键盘；关闭后回到触发入口。笔记标题、时间与操作菜单保持同行，长标题省略，菜单保留触控空间。

正文、标签等自动保存；标题修改会规划重命名与引用更新。涉及歧义时先展示变更预览，保存失败保留草稿。刷新可恢复草稿，撤销历史仅在当前页面的有界编辑会话中保留。

专注模式收起辅助面板，保留导航和退出入口。阅读字体、行高、打字机模式与布局偏好保存在当前浏览器，不进入内容同步。

## 常用操作

| 快捷键或入口           | 操作                                         |
| ---------------------- | -------------------------------------------- |
| `Ctrl/⌘+K`、`Ctrl/⌘+O` | 知识库命令面板                               |
| `Ctrl/⌘+F`             | 文内查找                                     |
| `/`                    | 插入标题、列表、任务、代码、表格、日期或模板 |
| `[[`                   | 补全笔记链接                                 |
| `Ctrl/⌘+B`             | 正文中加粗；正文外切换侧栏                   |
| `Shift+F10`            | 打开编辑器上下文菜单                         |
| `Escape`               | 优先关闭当前浮层，再退出专注等状态           |

今日日记按设备本地日期复用同一篇笔记，不覆盖已有正文。带 `模板` 或 `template` 标签的笔记可作为模板插入，支持 `{{title}}` 与 `{{date}}`。

桌面正文右键保留或调整当前选区，提供剪贴板、格式、插入与链接操作；Shift＋右键使用系统菜单。手机保留原生选字菜单。正文改动进入 CodeMirror 撤销历史；异步剪贴板操作落地前检查正文与选区是否变化。

本地附件可直接预览，外部图片由用户主动加载。图片、二进制同步与文本提取见[附件说明](KNOWLEDGE-ATTACHMENTS.md)。

## 链接与重命名

支持 `[[笔记标题]]`、带别名或标题锚点的双链，以及相对 Markdown 链接。补全生成稳定 ID 引用，文件夹相对路径与解析优先级见[路径说明](KNOWLEDGE-PATHS.md)。

- 同名或缺失目标先打开选择／创建界面，不自动猜测。
- 编辑器重命名可更新唯一指向该笔记的引用，并保留显示文字和标题锚点。
- 变更计划记录基准版本；笔记、草稿或冲突状态变化后，旧计划会被拒绝，避免部分更新。
- 引用式链接进入关系索引；需要改写时仅转换受影响的文字引用，不破坏共用定义。
- 代码、转义文本、图片与 HTML 节点不作为普通关系链接处理。
- 远端同步与 Agent 单篇编辑不会隐式批量改写其他笔记。

当前不提供块引用、`![[嵌入]]`、YAML 别名解析或完整 Obsidian Vault 兼容层。

## 实现入口

源码位于 [knowledge/](../apps/studio/src/knowledge/)：

| 目录                    | 职责                                       |
| ----------------------- | ------------------------------------------ |
| `workbench/`            | 页面组合、操作、导航、资源列表与个人偏好   |
| `editor/`               | CodeMirror、阅读视图、草稿、选区与编辑会话 |
| `notes/`                | Markdown 分析、路径、链接和变更计划        |
| `session/`、`storage/`  | 唯一状态服务、串行写入、历史与备份         |
| `attachments/`、`sync/` | 附件与 GitHub 同步                         |
| `agent/`、`search/`     | 编辑目标、工具和增量搜索投影               |

关系索引可从正文重建，不是另一份正文。界面通过 Store 提交修改，不直接写持久化数据。详细生命周期见 [Runtime 架构](RUNTIME-ARCHITECTURE.md#领域服务与代码职责)。
