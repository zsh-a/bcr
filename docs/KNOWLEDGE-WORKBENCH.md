# 知识工作台：第一阶段

知识工作台在现有 Markdown、草稿恢复、GitHub 同步和 Agent 审批写入之上，补齐日常写作与知识关联体验。现已加入[可读路径与文件夹](./KNOWLEDGE-PATHS.md)：仅在首次写入路径数据时备份并升级状态格式，不在打开时批量迁移；不是完整的 Obsidian Vault 或社区插件兼容层。

## 使用

- **命令面板**：侧栏入口或知识库活动时的 Ctrl/⌘+K（Ctrl/⌘+O 为别名）。分为「笔记」与「操作」两组，笔记支持标题、标签、正文检索，↑↓ 选择，Enter 打开，Escape 取消；中文输入法确认不触发打开/创建。无结果时可明确创建笔记，同名笔记列出不同 ID，不静默选择目标。「操作」提供新建笔记、今日日记、打开版本历史、打开同步设置、备份与恢复、导出当前笔记、移动／重命名／删除当前笔记、导入 Markdown、从资料集合导入、导出知识库、关闭其他标签等入口；只在当前上下文可用时才列出（例如未打开笔记时不显示「导出当前笔记」）。
- **显式标签页与导航**：单击列表只「访问」当前笔记，不隐式开标签；双击、Enter、命令面板、正文链接或导入才显式打开一个标签页。每个标签页可固定（固定标签保留）或关闭，保留最多 20 个标签页、50 条最近访问记录，支持收藏。关闭最后一个标签页回到空状态（没有打开的笔记）。标签页、最近访问、收藏只保存在当前浏览器，不进入 Git 同步或内容备份。
- **侧栏形态**：桌面侧栏有展开（约 300px）/ 图标栏（56px）/ 全隐藏三态。Ctrl/⌘+B 在展开与隐藏之间切换（与 VS Code 一致），要停在图标栏用侧栏里的收起按钮；命令面板另有「切换侧边栏」。形态随工作台偏好存于浏览器本地，刷新后保持。图标栏只留展开、搜索、新建与范围筛选，全隐藏后标签条左端出现展开按钮。小屏仍是抽屉，与桌面形态正交、互不影响。没有标签页时标签条整体收起，栏高从 44px 退回 36px。
- **正文排版**：文档列固定约 720px（含内边距约 37 个汉字/行，落在中文 25–40 字的舒适行宽），正文 17px，行高仍走阅读偏好三档。编辑区吃满剩余高度，CodeMirror 内部滚动，正文下方不再留大片空白；实时字符数收进标题下的文档工具行，不再单占页脚。阅读态长文仍由页面滚动，右栏 sticky 行程与阅读进度恢复不受影响。活动行高亮只在编辑器聚焦时显示，并压到很淡，避免变成横贯全宽的色带。
- **编辑状态**：当前工作区内最多缓存 20 篇笔记的撤销记录、选区和编辑器滚动位置；切换阅读模式不销毁编辑器。刷新后恢复正文依赖既有草稿机制，撤销记录不跨刷新保存。缓存正文与远端最新正文不一致时丢弃旧编辑会话，避免套用错误历史。
- **三种视图**：编辑、源码、阅读三选一（视图分段互斥，源码是逃生口）。编辑即实时预览，输入时把标题按层级装饰（约 22/18/16），并把简单双链渲染为可点击名称，隐藏非编辑位置的标题/强调/行内代码等标记；源码随时查看原始 Markdown，不改写存储正文。阅读按 GFM 渲染表格和任务列表。图片仍使用安全占位，不自动请求远端图片。专注模式（打字机、阅读字体/行高可选）收起侧栏、标签栏与状态槽，偏好存于本地 `bcr.knowledge.reading`。专注模式由外壳持有，因此命令面板可以进入/退出，Esc 也能退出（浮层、对话框或写作工具菜单在前时让它们先收，不抢 Esc）；跨笔记切换不重置。
- **写作辅助**：Ctrl/⌘+F 文内查找，列表续写，`/` 打开富插入面板（标题 1/2/3、无序列表、任务列表、引用、代码块、分割线、表格、日期，以及模板）替换旧的插入菜单与「插入模板」下拉。将普通笔记加上 `模板` 或 `template` 标签，即可在 `/` 面板或写作工具菜单的「插入模板」里插入其正文；支持 `{{title}}`、`{{date}}` 替换，不执行模板代码。写作工具菜单（工具图标；与「更多操作」⋯ 分工，后者跟文档操作走）按组用细分隔线分开：插入模板 / 视图 / 写作偏好 / 快捷键。其中「视图模式」三选分段（编辑/源码/阅读）在文档工具行已有同样的控件，主区宽度 ≥640px 时菜单里不再重复；主区更窄（分段收起）时才由菜单接管，保证视图与源码在任何宽度下都有且只有一个入口。标签在标题下方的文档工具行（与集合选择、字符数同行）维护：无标签时只有安静的「+ 标签」，点击进入输入，逗号/回车添加、退格删除最后一个，输入提示只出现在输入框占位符里。
- **今日日记**：按设备本地日期打开或创建同一篇日记。重复点击不会覆盖正文，创建仍经过草稿保存屏障。
- **大纲与链接**：上下文栏（大纲、反向链接、出站链接）在 ≥1100px 常驻侧置；窄屏折叠为标题下方的「大纲与链接」详情。各小节可折叠（默认展开大纲），大纲带 h1/h2/h3 层级缩进，长条目单行截断、全文退到 tooltip，滚动时高亮当前可见标题。支持标题定位、反向链接、出站链接及缺失目标提示；反向/出站链接为 0 时收敛成一行静默文案，说明文字退到 tooltip。
- **版式与列表**：标题独占一行，不与控件争宽；其下的文档工具行左侧是标签、集合与实时字符数，右侧是视图分段（编辑/源码/阅读）、写作工具与「更多操作」（移动/导出/收藏/版本历史/同步/删除，跟着文档走）。保存/同步状态簇挂在标签条右端，点击弹出同步详情；标签条只剩标签与状态。侧栏是文件系统式目录树（唯一的笔记列表）：控制收敛为新建、搜索行（筛选输入）与筛选行（范围分段 + 集合选择）；文件夹从笔记路径推导、缩进导轨分层，笔记行以标题命名、尾随相对时间（今天/昨天/N 天前，更早保留日期），单击访问、双击或 Enter 打开标签；树支持右键菜单（笔记/目录/空白三套）与拖放移动（落点高亮、一步撤销），「新建目录」以行内输入建目录（`/` 分层），非空目录删除先弹确认。侧栏输入只筛选笔记列表，与顶栏「搜索工作区」的全局搜索分工不同。空笔记（无标题无正文）降级为一行静默标题。文档列与右栏底部预留浮标安全区，右下「继续对话」不遮挡正文与出站链接。
- **历史、连接与恢复浮层**：桌面居中、手机底部展开，内容独立滚动，不推移正文。支持 Esc、遮罩及关闭按钮，Tab 焦点循环，关闭后返回触发按钮并保留正文滚动位置。关闭不会丢弃本次页面内的连接输入或备份预览；备份恢复成功后清空预览。操作进行中禁止关闭，恢复时仍校验预览后的内容变化。
- **实时重命名与歧义确认**：在标题框直接输入即触发重命名（约 600ms 防抖），自动改写唯一指向该笔记的引用，并弹出撤销提示「已重命名」或「已重命名并更新 N 处链接」，点「撤销」可回退。只有当修改计划遇到同名歧义引用（无法自动决定是否随重命名改写）时才弹出「确认重命名」对话框，逐篇展示受影响笔记与修改前后差异，可「确认全部修改」或「取消重命名」（取消不影响已保存的正文，焦点回到标题框）。正文、标签等始终独立自动保存。

## 链接语义

支持简单 `[[笔记标题]]`、`[[目标|显示名称]]`、`[[目标#标题]]`、`[[#当前标题]]` 和普通相对 Markdown 链接。`[[` 自动补全生成 `[[稳定ID|显示名称]]`，因此目标重命名不会改变引用身份。显示名称保持创建时的文字。

手写标题链接按 Unicode 归一化后的标题解析；同名或不存在的目标打开选择/创建界面，不自动写入。确认编辑器的重命名计划后，原本唯一指向该笔记的标题双链会转换为稳定 ID 引用，保留原显示文字、别名和标题锚点。笔记重命名、引用更新及历史记录在同一次持久化写入中完成；受影响笔记有未保存草稿或同步冲突时，整个修改会被拒绝。同名歧义链接不改写。

修改计划记录全部笔记的基准版本，应用时在保存队列中检查版本及草稿保护；计划生成后任何笔记的新增、删除或修改都会使该计划失效并被整体拒绝（不会遗漏新增引用或标题歧义，也不会部分写入），避免套用过期计划。这是当前采取的保守校验策略，尚未缩小到精确依赖集合。计划只在当前 Store 实例内有效，不跨刷新保存；被改动、重复执行或从外部复制的计划会被拒绝。普通自动保存不能再隐式触发跨笔记改名。此能力尚未作为 Agent 批量写入工具开放，现有单篇审批范围不变。

这项自动维护覆盖编辑器保存中的简单双链和内联 Markdown 链接。普通链接只替换目标地址为 `稳定ID.md#标题`，保留原标签格式、标题提示、空白及尖括号；外部 URL、图片和引用式链接定义不修改。远端同步带来的重命名不自动重写。Agent 的单篇编辑审批保持单篇范围，不隐式修改其他笔记。基础双链要求位于同一普通文本片段内，不支持跨强调/代码节点的复杂别名。代码块、行内代码、转义链接和 HTML 节点不进入关系索引。

引用式链接支持 `[文字][标识]`、`[标识][]` 和 `[标识]`，进入出站链接与反链索引；重复定义使用首个有效定义，未使用的定义、图片引用和未解析引用不进入关系索引。重命名时只将受影响的文字引用转换为稳定 ID 内联链接，保留原显示文字、格式和标题提示；原定义保持不变，避免影响共用定义的图片。不自动清理转换后未使用的定义。

源码模式支持 Ctrl/⌘+点击已识别的双链、内联链接或引用式链接跳转。源码跳转、实时预览中的双链、补全上下文验证与反链均使用 Markdown 分析器的链接语义；编辑器按不可变正文缓存分析结果，光标移动不重新分析正文。这不是增量全文索引或块级增量解析。

文件夹相对路径已支持，解析优先级和移动保护见[路径文档](./KNOWLEDGE-PATHS.md)。目前不解析 `![[嵌入]]`、块引用或 YAML 别名。

## 职责

- `markdownAnalysis.ts`：统一 Markdown 分析、阅读模式链接变换、目标解析与按正文缓存的关系索引。索引可重建，不是第二份正文。
- `renameLinks.ts`：基于重命名前的唯一解析结果规划双链和普通链接替换，保留其余原始 Markdown；`store.ts` 在保存队列内校验并原子提交。
- `changePlan.ts`：生成带基准版本和修改前后快照的重命名计划；`NoteRename` 展示范围、预览及确认。`store.ts` 负责计划签发、校验、一次性持久化与历史记录，不由界面直接写笔记。
- `editorAnalysis.ts`：按 CodeMirror 不可变正文缓存共享分析结果，使用弱引用避免额外保留废弃正文。
- `editorSessions.ts`：有界的临时编辑状态缓存；`draft.ts` 继续负责持久化草稿和保存屏障。
- `noteEditing.ts` / `livePreview.ts`：CodeMirror 补全、链接交互及显示扩展，不执行笔记存储操作。
- `workbench.ts` / `useWorkbench.ts`：校验、持久化浏览器个人布局与导航偏好。
- `NoteTabs`、`NoteSwitcher`、`NoteContext`：导航、搜索选择、上下文展示。
- `actions.ts` / `store.ts`：应用操作和唯一的持久化写入入口；原有同步、冲突和 Agent 校验保持不变。
