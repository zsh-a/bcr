# 工作区交互约定

工作区采用紧凑、内容优先的界面。所有 App 使用 `@bcr/react` 的视觉令牌和交互原语，领域组件负责内容与任务状态。

## 共享组件

- `AppToolbar`：56px 操作栏，提供唯一的工作区导航入口。标题、当前对象和操作留在同一行；搜索等必要输入可在手机端独立成行。
- `ActionMenu`：原生 Popover，承载次要操作与设置；重要操作保留文字按钮。`variant="menu"` 使用 240px 紧凑命令菜单与 `menuitem` / `menuitemcheckbox`，支持方向键、Home/End、Escape 和焦点恢复；默认 `panel` 用于包含输入与选择器的设置表单，保留触控高度。
- `ContextMenu`：原生顶层右键菜单，按指针定位并限制在视口内；方向键、Home/End 导航，Escape/Tab 关闭并回到触发对象，点击外部、滚动或改变窗口大小时关闭。菜单动作共享语义色与触控尺寸。
- `Dialog` / `Drawer`：原生模态对话框，统一背景隔离、Tab 循环、Escape 关闭、焦点恢复、触控关闭按钮和减少动态效果支持。响应式挂载通过 `useMediaQuery`，不以隐藏的 CSS 抽屉模拟模态。
- `Toast`：接收 `{ message, tone }`。成功、信息提示 5 秒后消失；警告、错误保留至关闭。悬停或聚焦暂停计时，错误使用 `alert`，其余使用 `status`。
- `EmptyState`：简短标题、用途说明、一个明确的下一步操作。空态不使用正在加载的骨架屏。
- `ResourceHeader`：资源范围或标题与一个主要创建入口，不堆叠多排操作。
- `ResourceSearch`：搜索独占整行；焦点框包围整个控件，清除按钮不挤压输入。点击清除或按 Escape 保留范围与输入焦点，输入法确认交给调用方处理。
- `ResourceViews`：安静的范围切换，方向键与 Home/End 切换，Tab 只进入当前项。可显示简短计数。

弹窗的视口定位由共享样式显式负责，不能依赖浏览器默认外边距。普通弹窗在视口居中，`Drawer` 始终靠右并占满高度；`placement="sheet"` 在手机端贴底，矮窗口中的普通弹窗改为底部全宽面板。

## 操作和内容层级

首次使用提供直接导入或新建入口，文案适应当前布局。示例内容标明来源；生成结果后突出下载、阅读或编辑。次要格式、处理配置与运行诊断进入菜单或抽屉。

文件摘要只保留名称、格式和关键规模；字段统计、队列和流程默认按需展开。手机端首先展示正文、表格、画布和可执行的下一步。上传区使用原生按钮，同时支持拖放。

技术运行信息保留在详情中。主界面使用“正在处理”“已保存到本机”“重新加载”等用户语言。数据来源和示例标识保持明确；成功、失败、空结果和加载态各有独立呈现。

## 字体与样式边界

共享辅助文字 12px、控件文字 13px、正文 14px。数字、文件校验值和代码可使用等宽字体；其他标签采用正文字体。容器缩小时，仅操作栏中的辅助按钮可以隐藏文字；空态主按钮和菜单文字保留。

App 的 `button { color: inherit }` 等重置必须排除共享控件，避免覆盖主按钮文字和语义色。圆角、间距、色彩和动效使用共享令牌；领域数据色、阅读内容与漫画画布仍按内容语义处理。

## 内容应用布局

Knowledge 使用一条 AppToolbar，合并对象标签、编辑模式、保存状态和次要操作。默认显示资源列表与正文；大纲、链接和可编辑属性共享按需打开的信息面板，宽屏侧置，低于 1100px 用原生模态抽屉。专注模式收起资源、标签和辅助信息，顶部仍保留退出与导航入口。

侧栏先选集合，再搜索，再切换全部／收藏／最近。普通浏览展示目录树；搜索、最近和收藏使用虚拟列表，保留相关度或访问顺序。清除搜索与重置全部筛选是两个明确的操作；空状态说明当前范围，并提供适用的下一步。

Reader 的书库和 Diagram 的图表列表使用同一搜索控件。Reader 工具栏、导航、书库与浮层跟随工作区主题，纸张／夜间／松石只改变正文视口和排版预览的颜色。

Reader 工具栏使用统一的图标按钮；漫画模式、快捷键帮助、安装和返回进入紧凑命令菜单。示例读物保留一个导入快捷入口，普通读物从菜单导入，避免重复。桌面命令行高 32px，触屏使用独立的 44px `--h-hit-target`；工作区导航也使用此令牌，保持目标大小，不受各 App 的控件密度覆盖。

Reader 快速书库使用轻量行，标题最多两行，次要信息只展示作者或格式与进度。缺少封面的读物用文件图标；文件大小和导入时间进入详情。当前读物用淡背景与细标记区分；收藏、重命名、详情和移除使用一个共享的右键菜单，支持 Shift+F10、F2 和触屏长按。长按移动或取消时停止计时，成功打开菜单后抑制本次点击，避免误打开读物。顶部“书库操作”提供管理当前读物、管理书库和备份入口。完整管理视图保留筛选、排序与批量选择，单本管理使用同一菜单；移除必须确认，移除后焦点回到搜索框。

## 验证

`test:browser:layout` 检查全部 App 的 4 种视口、导航入口、控件遮挡及页面溢出。`test:browser:ui` 在真实浏览器验证桌面、手机、横屏的弹窗位置、手机导入、原生模态焦点、错误持久提示、成功提示自动消失、首屏内容、直接下载，以及两种主题下的主按钮对比度。

`test:browser:resources` 检查 240px 侧栏、搜索排序、最近访问顺序、范围内清除、属性编辑、手机／平板信息抽屉和 Reader 的主题边界。

`test:browser:reader:menu` 检查 320–1440px 下的右键、键盘与真实触屏长按、菜单边界、焦点恢复、收藏与重命名持久化、移除确认以及嵌套书库管理。

`test:browser:reader:toolbar` 检查桌面、手机与横屏下的命令密度、文字标签、键盘导航、浮层焦点、两种主题、漫画模式以及单一导入入口。
