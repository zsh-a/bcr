# 债务与信用周期

入口：Market → 宏观 → 债务信用，或 `/markets?view=macro&layer=debt`。这个视图补充[月度周期监测](CYCLE-MONITOR.md)，分别观察部门杠杆、融资变化和偿债压力。现有年度全球比较及 Three.js 周期轨迹继续保留。

## 统计口径

**部门债务。** [BIS 核心债务统计](https://data.bis.org/topics/TOTAL_CREDIT)主要覆盖贷款、债务证券及货币和存款，不等于所有金融负债。住户包括为住户服务的非营利机构；非金融企业包含公营与私营企业。“私人非金融部门”是该统计框架下的居民与非金融企业，并非只包括私营企业。

一般政府优先使用完整名义估值序列；没有将更早的市场估值段拼到名义序列之前。居民、企业保留 BIS 来源口径。不同部门在合并及估值方面存在差异，结构图使用并列条形，不额外相加成“全社会总债务”。数据表和 CSV 逐条标明估值。

**偿债负担。** [BIS DSR](https://data.bis.org/topics/DSR)估计收入中用于本金偿还和利息支付的比例，不只是利息支出。期限等假设会影响绝对值，主要观察同一国家的历史变化，不按 DSR 的跨国绝对值建立风险排名。

**信用缺口。** [BIS 信贷 / GDP 缺口](https://data.bis.org/topics/CREDIT_GAPS)是私人非金融部门信贷 / GDP 比率减去单边 HP 长期趋势，单位为百分点。它用于描述金融脆弱性的积累，不是当季衰退判定，也不是信用增速或信用脉冲。

**本币同比。** `creditGrowth` 的计算为：

```text
本币信用同比 = (本季信用余额 / 四季前信用余额 − 1) × 100
```

要求同一来源、同一币种、同一完整序列的严格对应季度；缺期或上年余额不为正时留空。保留 BIS 的断点调整，没有额外消除汇率、估值和统计重分类影响。计算序列有独立指标 ID、来源代码后缀及 `derived` 状态，不冒充 BIS 直接发布的同比数据，也不与原始余额混存。

本币余额包含 CNY、USD、JPY、EUR、GBP。选择该指标时，趋势图仅绘制当前聚焦国家；各国读数保留币种，不能将不同货币金额直接比较。

**中国融资。** 人民银行社融原始统计表提供月度值。金额从亿元除以 10,000 换算成万亿元，未用年内累计值或累计差分代替当月值。社融包含股权等项目，不是纯债务或银行贷款；政府债券、企业债券和实体人民币贷款是其中的组成部分，不能与社融总量重复相加。净融资可为负，零与负值均保留。月度数据未季调，不把春节和季度末波动直接解释为转折。

**财政覆盖。** WDI 的 `GC.XPN.INTP.RV.ZS` 和 `GC.NLD.TOTL.GD.ZS` 来自 IMF GFS。它们常为中央政府范围，各国预算及合并范围不同，不能等同于 BIS 一般政府，也不与 BIS 债务直接拼接。

前者是利息支出占收入比例，不是扣除利息收入后的净利息负担。后者是收入减费用、再减非金融资产净投资后的净贷出或净借入，正为净贷出、负为净借入，不是现金收支差或初级财政余额。没有用预测填补中国、日本缺失；中国 2021 年等较早观测在读数中标明真实年份和“观测期较早”。详细定义见[利息支出](https://data.worldbank.org/indicator/GC.XPN.INTP.RV.ZS)和[净借贷 / 净借入](https://data.worldbank.org/indicator/GC.NLD.TOTL.GD.ZS)。

## 展示与交互

季度比较以各国可用私人非金融部门债务季度为锚点，窗口可选近 5 年、近 10 年或资源完整历史。拖动季度或通过选择器定位后：

- 部门比较只绘制所选季度的居民、企业和一般政府数据。缺失不按零处理，条形图不堆叠。
- 信用相位横轴为当季信贷 / GDP 缺口，纵轴为当季私人部门 DSR 减去本国此前 40 个连续季度的均值，均值不含当季。要求当季两个指标及之前完整 40 季都有值，缺期时不绘制该国当季点。
- 相位图显示此前 12 季轨迹，缺季断开；坐标尺度由所选窗口的所有有效点决定，拖动季度不重新缩放。零线是描述性基准，不是危机阈值或概率。
- 国家卡片、图形和分项读数联动。卡片可显示截至所选季度最新可用的观测，并注明真实期次；非当季观测不会改写日期。

下方趋势区独立提供“该指标最新数据”和“所选季度末”截止方式。默认可以查看截至 2026-09 的中国融资，同时保留上方 2026-Q1 的季度债务比较；切换历史季度时自动将趋势截到该季度末，避免在历史观察中悄然混入后续值。用户也可以显式切回最新数据，截止月份始终可见并保存在 URL。

月、季、年频率不重采样、不插值。来源完全缺期时，图表加入空值断点，但不把这些断点写成来源观测。数据表与 CSV 使用相同的指标、窗口及截止条件；导出保留原始精度、负值、空值、来源和完整口径。

这是当前修订版历史值，不是当时的信息集。回放和相位图不能据此宣称无前视偏差的交易回测。季度数据的较晚发布也不表示它们是当前月份的杠杆水平。

## 尚未引入

信用脉冲还需要口径一致的融资流量和名义 GDP 分母，不能以债务 / GDP 的变化或本币余额同比冒充。本版也未用缺乏同口径序列的数据推算短期外债 / 外储、外币债务占比或统一的一般政府财政负担。原始来源没有发布的分项保持缺失。

## 更新资源

```sh
bun run data:debt:sync --check
bun run data:debt:sync
bun run data:debt:sync --source=bis
bun run data:debt:sync --source=china
bun run data:debt:sync --source=fiscal
```

`--check` 只读并校验本地资源。更新分别取得 BIS、人民银行、WDI 原始来源；先验证再用同目录临时文件原子替换，失败来源保留旧文件并返回非零退出码，不影响其他成功来源。同比计算在加载时从本币余额生成，不另行保存重复派生资源。更新后重新构建发布。

BIS 使用 SDMX v2、指定 CSV Accept 头并批量选择五国；政府名义估值、单位、倍率、部门、频率及调整类型均验证。人民银行解析官方年度统计目录及原始月度 HTML 表，识别 GB2312/GBK 编码和字段位置。WDI 校验分页、国家目录与指标代码，排除无观测序列及当前年份、不引入额外国家。

数据遵循[BIS 使用条款](https://data.bis.org/help/legal)、人民银行原始网页声明和[世界银行数据许可](https://datacatalog.worldbank.org/public-licenses#cc-by)。界面与数据来源说明保留 BIS 署名及“中文为非官方翻译”声明。
