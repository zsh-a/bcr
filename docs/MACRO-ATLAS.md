# 全球宏观看板

入口：Market → 宏观，或 `/markets?view=macro&layer=history`。独立开发入口运行 `bun run markets`，打开 `http://localhost:5202/markets?view=macro&layer=history`。

看板提供年度宏观指标比较、历史事件轨道、增长与通胀相位图。国家、指标、时间范围、事件分类及选中事件保存在 URL 中，可复制链接恢复。

月度 CLI、PMI、生产、需求、就业、金融信号及可选 Three.js 周期空间见[经济周期监测与三维可视化](CYCLE-MONITOR.md)。入口为宏观页的“周期监测”，或 `/markets?view=macro&layer=cycle`。

分部门债务、偿债负担、信用缺口及中国融资见[债务与信用周期](DEBT-CREDIT.md)，入口为“债务信用”，或 `/markets?view=macro&layer=debt`。

## 随项目发布的数据资源

真实世界银行 WDI 数据位于 [`worldbank-snapshot.json`](../packages/market-data/src/macro/worldbank-snapshot.json)，作为宏观页面的延迟加载资源打包；页面默认不请求外部数据接口。冻结资源包含 217 个非聚合经济体、1980—2025 年的六项年度指标。元数据保留来源、许可、抓取时间和来源更新日期；具体覆盖以快照内容为准。

| 指标           | WDI 代码            | 口径                                 |
| -------------- | ------------------- | ------------------------------------ |
| 实际 GDP 增速  | `NY.GDP.MKTP.KD.ZG` | 不变价年度增长率，%                  |
| CPI 年度通胀率 | `FP.CPI.TOTL.ZG`    | 年度价格变化率，非某月同比或年末同比 |
| 名义 GDP       | `NY.GDP.MKTP.CD`    | 现价美元，受价格与汇率影响           |
| 人均 GDP       | `NY.GDP.PCAP.CD`    | 现价美元，未作 PPP 调整              |
| 失业率         | `SL.UEM.TOTL.ZS`    | ILO 模型估计，%                      |
| 贸易开放度     | `NE.TRD.GNFS.ZS`    | 进出口总额占 GDP 比重，可能超过 100% |

缺失数据保留为 `null`，真实的零保留为 `0`；不插值，不跨空缺连线，不把最近有效年份改成当前年份。顶部卡片显示所选结束年份之前最新的有效观测，并注明真实期次。CSV 导出原始数值精度；屏幕数值使用便于阅读的格式。

更新项目内置资源：

```sh
bun run data:macro:sync
```

脚本向官方接口下载国家目录和完整分页数据，校验分页总数、修订日期一致性及基本覆盖，成功后在同一目录原子替换资源。下载或验证失败保留原文件。数据资源更新后需要重新构建应用才能随版本发布。

页面的“手动更新”只拉取当前选择的经济体，结果写入 `markets` 命名空间下的 OPFS `macro/annual.json`。下次打开会按“经济体＋指标”合并缓存和内置资源，优先使用来源更新日期较新、其次抓取时间较新的序列；不会让最近仅更新过一个国家的旧缓存覆盖新版资源中的其他国家。存储不可用时仍可查看内置数据，在线失败保留当前数据。打开宏观页不会恢复或请求证券行情。

## 可视化交互

- React 配合按需注册的 ECharts，采用 SVG 渲染；图表随容器尺寸和工作区主题变化。
- 最多比较六个经济体，可按中文名、英文名或 ISO 代码搜索。
- 趋势图和事件轨道共享年份范围，可拖动滑块、按住 Ctrl 使用滚轮缩放，也可通过年份控件操作。
- 图例按钮可聚焦一个国家，再次点击恢复；支持键盘操作。悬停时图例同步显示该年读数，移出后恢复最新可用值。宽屏曲线末端标注真实期次和值，并避让密集标签。
- 历史事件按五类分轨并按年度对齐，持续事件显示区间；同年同类事件聚合为带数量的标记，点击可逐条选择。日期原始精度保留在详情和来源中。点击事件聚焦前后三年。
- 相位图横轴为实际 GDP 增速，纵轴为年度 CPI 通胀率；圆点大小示意当年名义 GDP，渐隐轨迹显示前五年。年份可拖动或播放，坐标范围固定为所选经济体与时间范围，保留历史极端值。任一坐标缺失时不绘制当年圆点；GDP 缺失时使用未按规模缩放的空心圆。
- 图表同时提供数据表与 CSV；支持明暗主题、窄屏国家选择器和系统减少动态效果偏好。

## 历史事件

[`events.ts`](../packages/market-data/src/macro/events.ts) 是附来源的精选背景库，包含危机、政策、地缘、公共卫生和贸易事件。每条记录保存日期精度、涉及经济体、摘要、观察方向和来源。空国家标签表示全球背景；标签表示参与或涉及，不是量化的影响范围。

年份和国家筛选采用区间重叠及国家交集，全球事件保留为共同背景。事件前后表使用起始年前一年与结束年后一年，并保留缺失值；它展示同期变化，不能单独作为因果推断。该库不是完整经济史年表或实时新闻流，新增内容需核对原始资料。2026-10-27 补充近期精选节点，最新收录事件为 2026-10-19；公告日、实施日、年度计划和政策沟通在摘要中分别注明。年度图表仍受指标年份限制，可通过“查看近期事件”进入统一工作台查看 2026 年事件。
