# 资料引用

全局搜索的 Reader 正文、Document 原文/译文、Media 字幕投影提供 `CitationSource`：
`scope` 标识章节、文档字段或源媒体，`unit` 标识章节/内容块/字幕条目，`offset` 是投影在该单元内的原始 UTF-16 起点，`version` 是正文版本的 BLAKE3 摘要。文档版本包含块 ID 与正文；媒体版本包含字幕顺序、时间、原文和译文。

`SearchResult.match` 指向实际正文命中。NFKC、大小写和连续空白规范化均保留回到原始 UTF-16 的映射，组合字符按 grapheme 处理。支持引用的投影对重复命中分别返回结果；标题/标签匹配不会伪造正文命中。

保存命中时，`TextCitation` 记录有界句子/上下文、前后文、实际命中在摘录内的范围、来源版本和位置。路由的 `cite` 参数携带该契约，因此导出的引用链接不依赖临时内存或 Blob URL。集合中的新字段为可选字段，既有 v1 集合与旧版整段摘录仍可恢复；旧摘录不会被自动赋予未经核验的版本。

## 核验与回跳

- 版本一致且原位置正文完全匹配：按原始命中范围定位。
- 版本或位置变化：在同一来源范围内查找原文，以前后文区分重复候选；只有唯一候选才重新定位。
- 多个候选无法区分：显示需核对，不按距离选择一个位置。
- 正文已被改写或删除：保留保存时的摘录，停止精确回跳。
- 来源应用尚未重新发布：显示待核验，允许打开来源，由来源应用读取当前数据后再次核验。

Reader 的重叠片段在核验时按单元与版本拼接；返回范围为单元中的原始 UTF-16 位置。Document 的原文和译文分别核验，避免用译文偏移切原文。Media 的字幕时间与数组下标只作为旧位置，内容核验成功后使用当前字幕时间并选中该行。

集合状态根据当前来源投影计算，不把磁盘中的历史搜索索引当作当前来源。来源应用还会在打开链接时独立校验，防止索引过期导致错误定位。状态描述正文定位的可用性，并不代替二进制源文件的完整备份。

## 验证

`packages/core/tests/citation.test.ts` 覆盖原始偏移、组合字符/全角/空白、重复正文、前后文消歧、正文插入与跨片段移动、损坏契约以及索引恢复后的未核验状态。领域测试补充文档字段隔离、block ID 改变、字幕时间调整和改写后的拒绝定位。

`node scripts/verify-research.mjs` 使用隔离 Chromium 验证真实导入、摘录、笔记、刷新、Markdown 下载、Reader 命中进入视口与高亮、Document 原文高亮，以及 Media 时间修改、正文改写和清空项目后的状态变化。该脚本已纳入浏览器 CI。

## 集合管理与个人笔记

集合支持重命名、删除确认和跨集合移动。移动在一次资料库写入中完成，保留正文、引用、版本与个人笔记；目标已有相同摘录时拒绝移动，避免覆盖笔记。删除集合不删除源文件。

个人笔记区与来源正文快照分开。输入时同步保存草稿到当前站点的浏览器 localStorage；切换面板、筛选、移动摘录和刷新后恢复。草稿按摘录快照身份关联，移动不改变身份。草稿写入失败时保留当前会话输入并提供重试；此时刷新不能保证恢复。点击「保存笔记」后才写入 SQLite 资料库，Markdown 仅导出已保存笔记。保存期间的新输入不会被旧保存结果清除。草稿不跨浏览器同步；删除后的孤立草稿在资料库成功加载或更新后清理，失败时可重试。

## 集合备份 v1

「资料集合 → 集合备份与恢复」下载全部集合的 JSON（`format: bcr-research-backup`, `version: 1`）。默认只含已保存笔记，勾选后额外包含当前草稿。源文件、搜索索引和派生 Artifact 不在本版范围内；不能把成功导入集合视为源文件已恢复。Markdown 仍只用于阅读导出。

导入文件上限 16 MiB，在读取前检查文件大小，解析后校验版本、日期、集合/摘录身份、引用与本地路由。预览列出集合、摘录、草稿数量及新增/跳过/冲突副本数量；确认后一次性写入资料库，失败保留原库并允许重试。相同 ID 与内容的集合跳过；内容冲突或草稿身份碰撞时导入为独立副本，不合并或覆盖已有笔记。副本使用确定性身份，重复导入未修改的副本不会继续复制。

导入草稿以可选 `ResearchExcerpt.draft` 保存在 SQLite 中，普通编辑仍同步写入浏览器草稿存储；这让集合、引用和导入草稿能在一次持久化操作中恢复。点击「保存笔记」后清除该恢复字段；清理旧草稿不会清除保存期间的新输入。旧 v1 集合无需迁移。

草稿读取失败会明确提示并暂停编辑，重试读取不会覆盖尚未恢复的文字。写入失败仍保留内存输入；保存笔记成功后解除错误状态。成功加载或修改集合后清理已删除摘录的孤立草稿，只处理 BCR 资料草稿命名空间；清理失败可重试。清除源文件的行为不属于集合删除。

生产 Studio 由 `createBrowserRuntime` 获取 `bcr:project:studio` 的浏览器独占锁，第二个标签页无法再次打开可写项目。锁覆盖运行会话与关闭刷新阶段；`ResearchStore` 自身的写入队列仍只保证实例内串行。

`node scripts/verify-research-backup.mjs` 已加入浏览器 CI：导入预览/取消、损坏备份、重复导入、冲突预览、浏览器存储读写故障、保存后的移动恢复、真实下载、全新存储上下文恢复、手机布局、刷新、删除草稿清理及第二标签页项目锁。

## 搜索个人笔记与摘录

全局搜索新增「资料集合」范围及集合下拉筛选。已保存笔记与正文快照分别投影为 `research-note` / `research-excerpt`，结果显示所属集合和命中字段；只有标题、来源或集合信息匹配时明确显示元信息命中，不伪造正文命中。

点击结果的「打开笔记」进入对应集合卡片并滚动定位。正文命中高亮保存快照；笔记命中单独显示已保存笔记与高亮，编辑框继续保留当前草稿，不以旧搜索文字替换输入。高亮前再次比对原文范围，已变化的文字不会被错误标记。「回到原文」沿用原有来源核验与引用路由。

资料库成功加载、导入或写入后重新发布集合投影，集合改名/移动/删除和清空笔记均清理旧条目；失败写入不发布。刷新后兼容恢复已持久化的新结果类型，再由已加载的资料库校正投影。草稿不进入索引。长字段按 1,800 字符分片、重叠 120 字符，路由记录分片原始 UTF-16 起点，映射到完整笔记后高亮。相邻分片可能分别返回同一处重叠命中。

`/research?...` 是搜索面板内部定位信息，由面板消费；本轮不提供可从地址栏直接打开的独立资料路由。它不会被保存为来源引用或代替原文链接。搜索仍基于关键词，不包含语义检索。

`node scripts/verify-research-search.mjs` 纳入浏览器 CI，覆盖草稿排除、集合筛选、长笔记 Unicode 高亮与可见性、修改旧命中失效、移动、更名、刷新、摘录正文定位、原文回跳和删除。
