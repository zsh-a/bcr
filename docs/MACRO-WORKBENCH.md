# 统一宏观研究工作台

入口：Market → 宏观，或 `/markets?view=macro&layer=research`。

默认在同一页面展示增长、通胀、政策利率、信贷增长、就业、领先景气、房价及偿债负担。主题预设只调整可见指标，国家、焦点、日期、时间范围和钉选继续共用。年度背景、周期空间和部门债务保留在“专用图表”中；带 `indicator`、`from` 等年度参数的旧链接及 `layer=cycle/debt` 继续可用。

## 数据与查询

`packages/market-data/src/economy/` 为统一只读边界：

1. `adapters.ts` 将现有 annual/cycle/debt 资源转换为公共序列。原始领域模型作为来源适配契约保留。
2. `repository.ts` 建立经济体、指标与序列索引。指标使用 `annual:`、`cycle:`、`debt:` 命名空间，原始序列身份保留来源标识、频率和调整信息。年度通胀不覆盖月度 CPI。
3. `query.ts` 统一裁剪参考日期、选择读数、计算严格相邻期变化和窗口覆盖。图表、表格和 CSV 使用同一查询结果。
4. `export.ts` 统一格式和导出，保留展示值、原始值、单位、币种、频率、调整方式、来源、许可、日期、计算标记和公式说明。

冻结资源包含 217 个经济体、64 项指标、1,453 条序列、89,586 个原始期次。不同指标覆盖不同经济体，不将美国专项调查外推为全球数据。

`points` 只含窗口内原始记录；`plot` 额外插入月、季、年频的空期用于断线，不进入导出。日、周频不猜测节假日或应发布次数。季度按季末、年度按年末对齐 UTC 参考日期，不插值成月度数据。

最新读数可以回溯至较早的最后有效值，必须展示其实际期次和距截止月份。鼠标或固定光标按窗口内不晚于参考日的最后原始记录读数，保留该记录的 null，不跳过空值。参考期截止并非历史信息可得日期；当前资源未构建完整数据 vintage，回放不能作为无前视偏差回测。

页面不自动请求官方接口。年度数据复用原年度视图的可选 OPFS 缓存，因此从专用图表手动更新并保存后，返回工作台可以读取同一年度资源。周期和债务仍使用打包资源。

## 状态与交互

`research/state.ts` 是研究条件的统一事实来源；URL 保存 `countries`、`rFocus`、`rFrom`、`rTo`、`rDate`、`rAsOf`、`rPreset`、`rPins`、`rEvent`。未知指标、非法日期和超出资源范围的输入会校验并归一化。全局选择最多 6 国，跨主题钉选最多 8 项。

共享光标与固定状态为短暂交互，不在每次鼠标移动时写 URL。图表使用 UTC 日期联动，不按数组位置或各自百分比缩放对齐。固定日期、图内键盘、触摸及解除动作共用上层状态；鼠标联动只移动竖线和读数，不重新执行整张图的 `setOption`。

国家颜色绑定国家 ID，选择顺序变化不重新分配。不同币种金额仅展示聚焦国家，图表、表格和导出应用同一过滤，不把不同货币混成一个纵轴。缺少月度资源的国家可以查看明确标注的年度背景，全球国家选择不会被子视图过滤后永久删除。

事件轨道默认按国家与时间筛选，近期事件在前。可切换“当前窗口 / 近两年 / 全部收录”，后两种范围不受图表时间窗口约束，窗口外条目明确标注并可点击定位；国家筛选始终保留。事件库页面显示人工更新日期和所选国家的最新收录日期，这是静态精选库，不是实时新闻流。选择事件同时定位所有面板窗口。年、月精度事件按对应完整期间展示，不制造精确日期或自动推断因果关系。来源、公式、原始表格通过右侧抽屉展开。

CLI 详情中可展开 Three.js 轨迹，与工作台共用国家和观察截止，使用不晚于截止的可用 CLI 月份。默认二维工作台不加载 Three.js。旋转、缩放、键盘、按需绘制和 WebGL 不可用回退沿用[周期空间](CYCLE-MONITOR.md)实现。

“保存布局”写入本机 `bcr:macro-research-layout`，恢复时重新校验；分享链接携带研究条件。存储不可用时可继续使用链接。

## 兼容与维护

`legacy-state.ts` 负责旧参数迁移和专用视图投影。三套旧 URL serializer 只替换自身字段，保留其他领域参数；已存在的统一研究条件仅在用户明确改变相应条件时同步。仅切换指标不会把“最新”变成历史日期。

周期与债务维护脚本共用 `scripts/lib/snapshot-sync.ts` 的参数校验、只读检查、完整性校验及原子替换；来源解析器继续各自校验官方维度。年度维护保留其紧凑编码流程。来源失败保留原资源，成功来源可独立更新。

```sh
bun run data:cycle:sync --check
bun run data:debt:sync --check
bun run test:browser:research-workbench
```

统一工作台浏览器验证可通过 `BASE_URL` 指向独立 Market 或 Studio。数据与状态边界测试位于 `economy-*.test.ts`、`research-*.test.ts`；固定光标的独立浏览器回归为 `apps/market-board/tests/research-chart-lock.browser.mjs`。
