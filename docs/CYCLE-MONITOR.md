# 经济周期监测与三维可视化

入口：Market → 宏观 → 周期监测，或 `/markets?view=macro&layer=cycle`。年度全球比较和历史事件继续保留在“长期比较”。本页关注月度周期信号，不把年度 GDP、月度 CPI 或不同频率的数据强行合成一个分数。

季度部门杠杆、偿债压力、信贷缺口和月度中国社融已在独立的[债务与信用周期](DEBT-CREDIT.md)视图提供，保持各自统计频率与来源口径。

## 已引入的关键数据

冻结资源覆盖中国、美国、日本、德国、英国。当前合并后为 41 类指标、91 条序列（含 8 条明确标记的计算序列），共 23,115 条观测，其中 23,019 条为有效数值。2026-10-25 在原有领先景气、实体活动和价格指标之外，补充政策传导、住房、就业边际、贷款调查、短期价格动量和信心数据。指标按实际覆盖显示国家数量；美国特有的调查不外推为全球指标。具体观测期次、抓取日期和来源更新日期以页面覆盖矩阵为准。

| 观察维度   | 已实现                                                                 | 覆盖与用途                                                           |
| ---------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 领先景气   | OECD 振幅调整 CLI                                                      | 五国月度，2000-01 起；判断相对长期趋势的位置与方向                   |
| 订单与调查 | 制造业 PMI、新订单、非制造业商务活动                                   | 中国官方原始表 2025-09—2026-09；非制造业包含建筑业                   |

| 金融预警   | 美国国债 10 年－3 个月利差                                             | 原生日度、百分点；方向提示未来风险，不等于当前衰退                   |

[OECD CLI 定义](https://www.oecd.org/en/data/indicators/composite-leading-indicator-cli.html)强调相对趋势的周期转折信号；本页据此将 CLI 水平与三个月变化组合展示，不将四象限命名为正式衰退或复苏判定。中国 PMI 来自[国家统计局原始发布表](https://www.stats.gov.cn/zwfwck/sjfb/202609/t20260930_1965449.html)，政策与房价来自 [BIS](https://data.bis.org/)，信心来自 OECD 标准化序列；美国观测通过 [FRED 官方 CSV](https://fred.stlouisfed.org/)下载，序列内注明 BLS、BEA、Federal Reserve、DOL 等原发布机构。

数据加载边界：

- 页面读取 `packages/market-data/src/cycle/*-snapshot.json`，不自动联网，也不依赖密钥。周期页面和三维代码各自延迟加载。
- 月、季、周、日频率及单位保留；未发布、缺失与真实零分别处理。月、季度完全缺期会在图表中加入空值断点，仅用于断开线条，不伪造资源观测。
- 工业、实际消费、零售、非农和收入的月度水平序列，趋势图计算严格同月同比；原始值同时进入数据表与 CSV。美国 CPI 使用严格同月上年计算，保持来源季调说明。
- 分项动量为相邻三个月均值之比减一，**不折年**；要求六个连续有效月和季调数据。条件不足则使用同比或显示缺失，超过两个月的生产、需求、就业数据不会充作当期状态。
- 月度时间轴由可用 CLI 决定，当前观察截至 2026-09；周度初请、日度利差资源可更新至 10 月，覆盖矩阵显示其原始最新日期。默认图表与导出仅展示截至所选观察月份的观测。趋势面板可显式切换为“该指标最新数据”，独立于上方 CLI 相位；开始回放或移动观察月份后恢复历史截止，避免把最新值混入回放。空值尾部保留在趋势截止范围内，旧的有效值会标出实际日期。
- 整条序列按最新有效观测日期、其次抓取时间选择；不拼接不同基期或季调方式。FRED 不覆盖 OECD 的 GDP 同比，因为美国 SAAR 使用独立指标 ID。
- 来源未给出发布日期时保留 `null`；抓取时间不能冒充发布日期。多数国际序列为当前修订历史值，中国实体指标按对应官方发布页提取；两者均未构建完整历史信息集，不能据回放宣称无前视偏差的回测结果。

## 新增指标的解释与计算

- **中国实体活动**：工业增加值为规模以上工业按可比价计算的单月同比，社零为未扣除价格因素的单月名义同比，就业为全国城镇调查失业率。房地产销售面积、新开工面积与开发投资均为年初至当月累计同比，不能当作单月增长。历史从 2025-06 起按固定官方发布页提取；工业、社零跳过 1—2 月合并数，其他实际缺月也留空，不从累计值倒算单月。
- **政策利率**：BIS 中国序列自 2019-08 起为一年期 LPR，此前为贷款基准利率；不是七天逆回购利率。德国采用欧元区利率，2024-09 的 MRO → DFR 切换不能当成普通降息。日本缺失月份不补零、不延续上一值。
- **事后实际利率近似**：月末政策参考利率减同月 CPI 同比，缺任一输入就留空；不是预期实际利率，也不提供统一的中性利率阈值。德国使用共同政策利率与本国物价，属于国别近似。
- **房价**：使用 BIS 已发布的季度名义/实际同比，不将季度值补成月度。中国覆盖 70 城，2016 年由新房切到存量房；日本 2008 年存在土地到住宅价格定义变化，国别说明中保留断点。美国开工和许可为 SAAR 水平，保留千套单位，未除以 12，也不是增速。
- **就业边际**：非农月增量为相邻两月季调就业人数之差，单位千人。失业率低点抬升为当前三月均值减最近 12 个月（含当月）三月均值最低值，要求 14 个连续有效月；这是美国描述指标，不是官方实时萨姆序列，不自动判定衰退。
- **核心通胀三月折年率**：`((I_t / I_t-3)^4 - 1) × 100`，要求四个连续、正值、季调的原始月度指数。2025-10 的美国原始 CPI 确实缺失，因此跨该月的计算留空，不能插值补齐。
- **私人需求**：采用 BEA `PB0000031Q225SBEA`，实际私人国内最终销售的季度季调折年增长率；不使用实际国内总收入序列代替。
- **信心**：OECD 的 `AA` 表示振幅调整，不能直接写成季调。BCI 仅覆盖制造业问卷；CCI 是家庭预期，不能当作实际消费。

趋势新增七类导航，卡片列出已选国家中的可用覆盖数；完整指标仍可从下拉框选择。每个国家的口径说明可展开，避免统一标题掩盖政策工具和调查范围差异。“数据时效与覆盖”列出实际最新有效期、距趋势截止的月份差、窗口有效记录比例、来源更新日期与抓取日期。月份差不等于发布延迟；日、周频不猜测交易日或应发布周数。

CSV 保留 17 列：国家、指标、原始期次、展示值/单位、序列值/单位、频率、季调、状态、来源、序列标识、来源链接、抓取时间、来源更新时间、许可链接、说明。计算值状态和公式、全部输入来源保留在导出中；计算值没有虚构的独立发布日期。

## Three.js 是否适合

结论是适合做可选的周期轨迹空间，精确比较仍使用二维图和数据表。这里第三个维度有明确含义：横轴为 CLI 水平，纵轴为本月相对三个月前的变化，纵深为历史月份。国家当前观测是圆点，连续月份形成轨迹；缺月断开，不用插值制造转折。

| 展示方式                   | 适用任务                                           | 本次选择                                                             |
| -------------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| ECharts SVG 趋势与二维相位 | 读数、比较方向、查看缺失、移动端分析               | 默认入口，支持表格、CSV、明暗主题和减少动态效果                      |
| Three.js 周期空间          | 同时理解周期位置、方向和时间轨迹，旋转查看重合国家 | 已实现，按需加载；最近 36 个月轨迹，共用回放窗口内的固定尺度         |
| 三维地球或立体 GDP 柱      | 地理位置和规模概览                                 | 暂不采用；透视和遮挡增加精确比较成本，地理位置本身也不能解释经济周期 |
| WebGPU 大规模粒子与流动场  | 需要大量真实空间对象、边或计算时                   | 作为后续实验；当前五国月度轨迹不需要额外渲染体系                     |

Three.js 官方说明当前 [`WebGLRenderer`](https://threejs.org/docs/pages/WebGLRenderer.html) 使用 WebGL2。官方 [WebGPURenderer 指南](https://threejs.org/manual/pages/webgpurenderer.html)仍将其标为实验性，并推荐纯 WebGL2 场景使用持续维护的 WebGLRenderer。因此本次选择 Three.js + WebGL2 + OrbitControls，不将能否使用 WebGPU 作为查看数据的前提。这是结合当前场景规模作出的工程选择，并非所有应用的性能结论。

实现约束与交互：

- 旋转、缩放、复位视角、当月圆点射线选国；上方国家卡片提供键盘和触控替代操作，画布支持方向键、加减键及 Home。
- 坐标范围包含所选历史窗口的极值，拖动月份时不重新归一化；纵深保持 36 个月跨度，因此窗口起点处可能只有少量已纳入的历史轨迹。
- 按[官方按需渲染方法](https://threejs.org/manual/pages/rendering-on-demand.html)，仅在交互、数据、主题或尺寸变化时请求绘制；无自动旋转和永久动画循环。标签页隐藏、组件离屏或工作区不活跃时暂停。
- 像素比上限为 1.5；月份和国家变化复用 renderer/context。卸载或更新几何时，按[官方资源清理说明](https://threejs.org/manual/pages/cleanup.html)释放几何、材质及标签纹理。
- WebGL2 被禁用、创建失败或上下文丢失时显示可重试提示；二维按钮和全部指标数据仍可使用。三维的透视、遮挡和角度变化会影响视觉读数，不能用画面距离估算精确经济差异。
- 不请求地图、远程字体或纹理；数据和三维资源随构建发布。页面初次渲染二维图时不会加载 Three.js。

## 资源维护

```sh
bun run data:cycle:sync --check
bun run data:cycle:sync
bun run data:cycle:sync --source=us-signals
bun run data:cycle:sync --source=bis-signals
bun run data:cycle:sync --source=oecd-confidence
bun run data:cycle:sync --source=china-activity
```

`--check` 只验证本地资源。更新时各来源独立抓取，先校验再原子替换；失败来源保留旧资源并返回非零退出码，其他成功来源可以更新。更新后重新构建发布。中国 PMI 与实体活动使用固定原始发布页以保证可复现，续期时需核实并更新 `china.ts` 或 `china-activity.ts` 中的来源 URL，再验证表头、列号、季调和覆盖范围。中国实体指标附表各期来源链接及整页发布日期保留在序列说明中。

OECD 使用批量 SDMX 请求；FRED 优先原生 CSV，部分公开统计系列保留 DBnomics / DOL 回退，实际取得哪个来源就在该序列记录哪个来源。当前冻结的美国资源均成功取得 FRED 原生观测。每条来源和许可链接在界面、资源与 CSV 中保留；CFNAI、NFCI 的再分发许可未明确，因此没有打包；商业 PMI 也未使用未经授权的数据。

## 后续数据边界

外汇储备与进口覆盖、短期外债和偿付期限、跨境资金流，以及其他国家的贷款调查仍需分别核对频率、国家范围和授权。金融条件综合指数应先解决再分发许可；正式衰退标记应采用各机构认定，不能由 CLI 象限或任意加权分数代替。
