# 年卡，去多少次才划算？

60 秒竖屏作品。目标读者是准备办健身年卡的人；只比较现金支出，价格为演示假设。
网页与视频共享 data.json 和 model.js。不要把价格假设写成实际市场调查。

## 视觉方向

编辑式动态图形：米白纸面、墨绿文字、橙色强调，最后一幕用深色背景和浅绿数字。
中文使用完整字集的思源黑体 CN；数字使用 IBM Plex Mono。字体与许可证在 public/fonts。
画面以 1080×1920 设计，保持左右 84px、上下约 100px 的安全空间。
大字、卡片、出勤格、圆环、曲线与横向对比交替出现。一次强调一个信息，结论留出阅读时间。

## 分镜

| sceneId    | 起止时间 | 表达任务                                 |
| ---------- | -------- | ---------------------------------------- |
| price      | 0–6 秒   | 年卡价格、立体卡片与反光                 |
| attendance | 6–16 秒  | 从办卡承诺转向实际出勤；格子错峰进入     |
| average    | 16–28 秒 | 平均成本随使用次数下降，数字与圆环同步   |
| comparison | 28–40 秒 | 两条成本线绘制，聚焦持平点               |
| scenarios  | 40–51 秒 | 比较三种出勤情景，统一数轴与金额来源     |
| decision   | 51–60 秒 | 给出严格更省钱的整数次数，并说明适用范围 |

src/motion.ts 是作品自己的镜头索引。过渡在后一幕开始时发生，前一幕延长以覆盖过渡；总时长仍由 work.json 决定。
转场音效由 tools/generate-audio.mjs 确定性生成。参数 sound 可关闭；样例未包含配音或背景音乐。

## 创作与验收

先读 AGENTS.md。修改视觉风格先生成三张风格帧，再导出前 15 秒检查运动和声音，最后验证完整作品。
推荐关键帧：90、360、660、1050、1350、1680。转场检查：170/180/190、470/480/490、830/840/850。
默认假设为年卡 1680、次卡 50，临界点 33.6 次，第 34 次起年卡严格更便宜。
另用 1800 / 50 验证：36 次持平，37 次起更便宜。每个数字由 model.js 计算，金额不使用弹簧过冲。
