# 趋势策略研究索引

截至 2026-10-03，尚无方案建立了充分、可迁移且经过真正未来行情验证的正期望证据。慢速通道有较好的历史盈利区间；`320/160` 曾通过一轮有限的历史转移门槛，但后续补全、扩大搜索及跨品种留出均未确认稳定优势。结构化回调两轮都在开发阶段失败，验证未解锁。

本页是旧证据的导航与结论汇总，不是新实验或收益排行榜。每轮的冻结规则、资金、窗口、引擎和评价口径以原文件为准；旧结论保留，后续结果不回写旧报告。

## 跨实验较稳定的认识

- **成本必须与初始风险一起看。** KDJ 的部分毛边际被费用消耗；PA 和某些历史压力窗在成本前已经亏损。慢速入场能减少总换手，但持有更久也可能增加资金费。账本加回成本不是零成本重跑，滑点已进入成交价，不能再次扣除。[成本对照](channel-recheck/ANALYSIS.md) · [长入场诊断](literature/ANALYSIS.md)
- **高胜率、少交易、小回撤都不能单独证明优势。** 早保本／较紧跟踪有时提高胜率却截短盈利尾部；严格形态有时只是消除了几乎所有交易。结论限定于已测规则，不能外推为保本、做空或价格行为永远无效。[退出对照](thirty-minute/ANALYSIS.md) · [严格结构结果](structured/ANALYSIS.md)
- **退出和账户限制会改变整条路径。** 日亏损保护也能退出跨日盈利仓位；关闭它同时改变退出、当日禁入、资金费和后续机会。分窗末平仓、持仓时间占比与少数大单依赖需要另看，不能用分类盈亏相减得到模块的因果收益。[风险消融](robustness/ANALYSIS.md) · [连续账户](search/continuous-attribution.json)
- **慢速通道的历史点估计最值得保留观察，但迁移证据不足。** 320/160 已经历选择、复核和跨币检验，不再是未研究假设；新六币的收益点估计低于旧六币，未检验两组差异的显著性，不能继续用旧样本的高收益替代留出失败。[跨品种结果](holdout/ANALYSIS.md)
- **机会标签与可执行账户分开。** 完整交易 MFE/MAE 被原退出截断；独立固定期限标签避免这种截断，却不含账户持仓冲突与完整风险预算。先达率、几何假突破、固定期限单位净 R，都不能直接改名为策略胜率或收益。[突破事件定义](thirty-minute/ANALYSIS.md) · [共同机会定义](structured-v2/ANALYSIS.md)

## 已被本轮验收拒绝与仍待验证的假设

已拒绝的是各轮**具体配置在各自冻结门槛下的有效性声明**：5 分钟 KDJ、早期严格 PA、当前结构回调，以及“关闭日保护的 320/160 已确立可迁移正期望”。这不证明整个指标或方法家族永远无效，也不抹去 details 的有限历史转移通过。

仍可形成新假设的方向包括：固定慢速通道的真正未来观察、结构回调中“推进背景关键位”能否配合更合适的退出、多尺度实际子资金组合。当前没有验证这些后续新组合。冻结 ATR 与动态 ATR 的更新时点、激活规则不同；已有 search 的退出对照也不能直接替代结构回调的专门检验。固定 +1R／+2R 止盈、突破缓冲或连续两次确认的**账户净收益**，不能从事件标签反推。

## 后续研究的共同约束

1. **先固定问题，再解锁数据。** 数据目录只描述来源、覆盖和曝光；实验单独声明主假设、有限消融、标的／时间角色、成本、门槛、gap/purge。开发凭证须由真实账本复算，失败不改选目标域赢家。已有流程见[数据目录](structured/catalog.json)、[编译凭证](structured-v2/development-input/compilation.json)和[门禁记录](structured-v2/gate-check.json)。
2. **保持因果与成交一致。** 只用已完成 K 和已确认结构，信号后下一分钟执行；预热只作上下文，不计账户收益。新机制复用同一 Rust 成交与会计；配置／引擎／评价身份分别记录，不改写旧历史。
3. **账户比较保持可比，统计保留不确定性。** 明确总资本、实际子账户配置、所有成本与独立窗口重置；组合须按分配后资金重新执行。日终与分钟回撤、等权 R 与美元期望分别报告。保留亏损、零交易、未运行和全部预声明成本情景；重复策略、相关币种和重叠机会不是独立样本。
4. **冻结可复核证据，不覆盖旧结论。** 来源、计划、选择、原始结果、评价和审计以 SHA 绑定，新回放／报告使用新目录。冻结登记见 [frozen.json](../../scripts/trend/frozen.json)；本地冻结声明不等于第三方可信时间戳。Git 中的报告不等于本地完整行情、原始账本和历史二进制仍可用。
5. **结论限定于检验范围。** 不按亏损币或月份事后删样本，不把短样本年化、普通块区间或单次盈利写成长期能力。分钟 OHLC、固定滑点、静态合约规则及独立子账户没有验证盘口容量、清算和实盘故障恢复。
